# 三棱柱体素面邻接语义规范

## 目的

规定三棱柱体素之间何时可以形成**局部固定路径连接**。本规范只定义离散 Cell/Face 邻接和通行语义，不定义跨 Part 错视连接。

## 核心原则

两个可走面满足以下几何条件时，可以形成局部固定路径连接：

```text
面法线方向相同
  + 两个面位于同一连续平面
  + 两个面的对应边存在有正长度的线段重合
  + 两端 PathNode 可通行、方向语义兼容
  -> 局部固定边
```

“边重合”必须是有长度的线段重合，只有一个顶点接触不算邻接。

禁止使用以下规则直接建边：

- 仅凭两个节点距离接近；
- 仅凭两个面法线相反；
- 仅凭屏幕投影重合；
- 扫描所有节点并按最近距离连接。

屏幕投影、深度和遮挡只用于后续视觉候选评估，不替代本地面邻接。

## 面类型

一个三棱柱 Cell 有五个面：

```text
top      三角形上表面
bottom   三角形下表面
side_1   矩形侧面
side_2   矩形侧面
side_3   矩形侧面
```

面名必须与 `PathNode.face` 和 `TriPrismGrid:GetCellFaces()` 保持一致。

## Top / Bottom 面邻接

对于 `top` 或 `bottom` 面：

```text
两个三角形面存在有正长度的边重合
  + 两个三角形面的法线方向相同
  + 两面位于同一平面
  -> 几何上邻接
```

对应的两个 PathNode 还必须满足 `walkable` 和入口/出口语义。

三角形中心距离接近但没有边重合时，不算邻接；只共享一个顶点时，也不算邻接。

## Side 面邻接

对于任意 `side_1/side_2/side_3` 矩形侧面：

```text
两个侧面法线方向相同
  + 两个侧面位于同一连续平面
  + 面一的一条竖边与面二的一条竖边存在正长度重合
  -> 几何上邻接
```

竖边重合不能只是在顶点接触；如果两个面法线不同，即使共享竖边，也属于折角或转折关系，不按本规则建立同一平面的局部固定边。

两个节点还必须满足 `walkable`、`kind` 和入口/出口语义。

## Bottom 面语义

`bottom` 默认不是普通行走面：

```text
bottom -> 任意面
```

默认不建立局部固定边。只有未来明确增加特殊通行语义时，才允许单独配置例外规则。

局部固定边只检查：

- `walkable`：两端都必须为 `true`；
- `kind`：节点类型组合是否允许通过；
- 面的几何邻接关系；
- 运行时连接关系。
## 推荐实现流程

```text
PathNode(cell, face)
  -> 获取该面顶点和法线
  -> 在同一 Part 的候选 Cell/Face 中检查同向共面和边线段重合
  -> 查询邻接 Cell 对应面的 PathNode
  -> 检查 walkable / kind / 面几何
  -> 建立局部固定边
```

实现应优先复用：

```lua
TriPrismGrid:GetFaceNeighbor(cell, faceIndex)
TriPrismGrid:GetCellFaces(cell)
VoxelDocument:GetPathNodeAt(cell, face)
```

`GetFaceNeighbor()` 可用于缩小离散候选范围；最终几何判定以面顶点、法线、共面和正长度边重合为准。

不得通过 `PathRuntime` 遍历所有节点并使用世界距离推断局部邻接。

## 与跨 Part 视觉连接的区别

```text
同一 Part 内
  -> 使用本规范的 Cell/Face 离散邻接
  -> 生成局部固定边

跨 Part 或错视连接
  -> 使用 Level pathCandidates
  -> 固定游戏相机投影、深度、方向和遮挡评估
  -> 生成当前有效视觉边
```

两者不能混用：局部固定边不需要屏幕投影，错视候选边不能仅凭 Cell/Face 相邻创建。

## 当前实现状态

不稳定原型中的局部连接已开始按本规范使用：

```text
面顶点 + 同向法线 + 共面 + 正长度边重合 + 基础方向语义
```

该实现仍需通过更多密堆三棱柱样例验证，尤其是 `top/bottom` 三角面和三个矩形侧面的边界组合。
