# 六边形体素地编规范（第一版）

## 1. 基准体素

当前最小体素定义为：**等边三角形底面 + 垂直拉伸形成的三棱柱**。

| 参数 | 规范值 | 说明 |
|---|---:|---|
| 三角形边长 `a` | `1.0 m` | 体素底面每条边的长度 |
| 三棱柱高度 `h` | `1 / sqrt(3) ≈ 0.577350 m` | 由 30° 投影匹配关系确定 |
| 相机投影 | Orthographic | 禁止用透视相机作为基准地编相机 |
| 相机俯视角 `p` | `30°` | 相对水平面的俯视角 |
| 相机偏航角 `yaw` | `30°` | Game Preview 固定绕 Y 轴的设计角度 |
| 旋转步长 | `60°` | 六边形方向的离散旋转单位 |

## 2. 投影匹配关系

当三角形 Tile 的目标边沿相机深度方向时：

```text
h * cos(p) = a * sin(p)
h = a * tan(p)
```

第一版采用 `p = 30°`，因此：

```text
h = a * tan(30°) = a / sqrt(3)
```

使用 `a = 1.0 m` 时：

```text
h = 0.577350 m
```

这使三棱柱的垂直高度投影与下方三角形 Tile 的深度边投影重合，是后续纪念碑谷式错视连接的几何基准。

## 3. 网格方向

- 六向网格主轴必须固定，并与地编相机的深度方向对齐。
- UrhoX 的世界坐标为 Y-up 左手系；六向布局使用 `X = cos(angle)`、`Z = -sin(angle)`，与 `Quaternion(yaw, Vector3.UP)` 的正向旋转保持一致。
- 参与投影重合的 Tile 边必须沿相机深度方向；否则不能直接使用 `h = a * tan(p)`，需要额外乘以边方向修正项。
- 体素位置、旋转和机关状态使用离散六向坐标，不用任意浮点角度作为地编数据。

## 4. 地编数据约定

- 所有距离使用米。
- 所有旋转使用 `0..5` 的六向索引，实际角度为 `index * 60°`。
- 体素绘制器必须支持按网格坐标放置三棱柱，并允许单独指定颜色、朝向和高度层。
- 玩法逻辑中的连接关系独立于渲染模型；视觉重合不自动等于逻辑可通行，必须由关卡数据显式声明。

## 5. 视觉验证

每次调整 `a`、`h` 或 `p` 后，至少检查：

1. 三棱柱投影高度是否与目标三角形边重合；
2. 六个三棱柱拼接后是否形成连续六边形轮廓；
3. 相邻体素之间是否出现缝隙、重叠或错误遮挡；
4. 修改几何参数后，原本正常的预览画面是否回归。
