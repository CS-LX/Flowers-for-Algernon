# 第三章剧情台词

润色时请保留每句的 `id`、`mode`、`style`。改完把这份文件还给我，我会按 id 导回 `scripts/Story/Chapter3.lua`。

- `mode=modal`：锁输入，必须点完
- `mode=banner`：底部条，默认可走
- `style=charlie`：查理
- `style=researcher`：研究员等其他人，需要 `speaker`

第三章的核心语义：手术完成的瞬间，查理就已经失去了对世俗世界的空间观测能力。3-1 到 3-3 不是能力逐步衰退，而是查理逐步发现、验证并确信自己感知不到世俗世界。

这里的“世俗世界”包括行人、车辆、道路上的日常物件、旁人的活动痕迹，以及旁人的声音和城市生活回应。城市并没有真的消失；查理只能感受到泡在雾里的建筑、道路和桥，因此城市在他的观测中成为“空城”。

- 下降缓动为 **慢 → 快**；
