# 第五章关卡大纲与演出上下文

这份文件只记录第五章的剧情大纲、关卡功能、必须揭示的信息、当前导演演出和润色边界。具体对白请查看 `docs/story-chapter-5.md`。

---

## 一、第五章整体定位

第五章是查理陪伴阿尔吉侬、见证失去、并独自把花送到墓前的纪念篇。

第四章已经解释完手术真相和阿尔吉侬衰退时间线。第五章不再重新解释这些事实，也不再安排研究员。它只完成一个简单动作：

```text
陪伴阿尔吉侬
  → 见证衰退与失去
  → 沿着真实道路走向墓地
  → 送花
```

第五章固定为三关：

```text
5-1 真正的路
  → 查理带着衰弱的阿尔吉侬离开研究所，空间感知开始明显衰退

5-2 花园
  → 查理只能看见实体道路；阿尔吉侬在途中掉落并停下

5-3 余光
  → 查理独自顶着花，沿着逐段显现的真实道路抵达墓前并献花
```

章节情绪节奏：

```text
陪伴 → 艰难同行 → 失去 → 独自行走 → 献花
```

---

## 二、本章必须保持的统一事实

### 1. 不重述第四章真相

- 研究员已经在 4-4 解释过手术风险和阿尔吉侬衰退时间线。
- 查理已经接受自己因急于改变而选择手术的代价。
- 第五章不再出现研究员，也不再追问如何恢复能力。
- 查理离开研究所后，直接进入陪伴与纪念。

### 2. 查理的空间感知正在衰退

- 手术瞬间失去的是对世俗世界的空间观测。
- 第五章开始，查理连错视路径的判断也开始不稳定。
- 5-1 仍能看见并操作可活动路径，但机关会明显失灵。
- 5-2 起，查理只能看见真实存在的实体道路。
- 5-3 的道路是真实道路，不再依赖错视机关。

### 3. 阿尔吉侬已经无法独自完成这种路

- 5-1 开头，阿尔吉侬还在查理身边，但已经走不了可活动的错视路径。
- 查理主动把它接到头顶，两人一起走。
- 5-2 中途，阿尔吉侬从头顶掉落到实体路径上，不再移动。
- 5-3 不再出现阿尔吉侬活体；查理只带着花走向墓碑。

### 4. 结尾不恢复世界

- 人没有回来。
- 世俗世界没有恢复。
- 错视能力没有恢复。
- 花束成为画面中的纪念焦点。
- 结尾落在查理完成约定，而不是完成实验或拯救自己。

## 通用规则

- 进关先被近雾盖住；雾散完、关卡稳定后，导演才开始运行。
- `modal`：锁点击和走路，必须点完当前段。
- `banner`：底部条。第五章里，banner 用于查理行走中的短句。献花后的最后一句改用 `modal`。
- 查理始终处于固定正交相机下的六边形错视空间中。玩家点击可达 PathNode，让查理沿当前有效 Path Graph 自动行走。
- 玩家通过悬停、按下和拖动可旋转 Part，松开后机关 Snap 到合法的离散状态；Snap 完成后才刷新路径连接。
- 故障、载鼠、掉落、花和镜头拉近都是表现层演出，不改写 Path Graph 拓扑。
- 不要用“查理的眼睛”描述观测缺失。继续使用“空间观测”“空间感知”“看见路径”等既有概念。

## 5-1 真正的路

关卡感觉：复用 1-3 的反向地图。查理和阿尔吉侬刚离开实验室门。阿尔吉侬停在出生点；查理仍能看见可活动路径，但空间判断已经开始失灵。

### 关卡开场

**触发：** 雾散、关卡稳定后，导演立即锁输入并播放 `ch5.1.intro`。

**玩家状态：** 锁输入、锁走路。

**画面：** 查理和阿尔吉侬都在出生点。阿尔吉侬不主动探索。旋转机关已配置故障，但开场对白期间玩家还不能操作。

**这段在干什么：** 简短交代世俗世界已经看不见，空间感知也开始衰退；同时确认阿尔吉侬还在查理身边。

**说完：** 解锁输入和走路。玩家开始探索可活动路径。

### intro · `ch5.1.intro`

**触发：** 进关后立刻播放。

**玩家状态：** 锁输入、锁走路。

**画面：** 实验室的门已经在身后。阿尔吉侬停在出生点，没有跟上。

**这段在干什么：** 把第四章结尾接到第五章开头。查理不再追问手术原因，而是承认自己正在衰退，并决定带阿尔吉侬一起走。

**说完：** 进入可玩状态。

### discover · `ch5.1.discover`

**触发：** 查理抵达任意 `rotator_end1`、`rotator_end2` 或 `rotator_end3`。

**玩家状态：** 锁输入、锁走路。

**画面：** 查理已经踏上可活动路径。阿尔吉侬仍停在出生点。

**这段在干什么：** 查理发现这段路可以重构，同时意识到阿尔吉侬已经走不了这种路。他决定把它接到自己头顶。

**说完：** 查理自动沿当前有效 Path Graph 返回出生点。

### 接鼠演出

**触发：** `discover` 说完后立刻开始。

**玩家状态：** 锁输入。查理自动返回出生点。

**画面：** 查理走回阿尔吉侬身边。阿尔吉侬以短弧线跳上查理头顶，并缩小到适合携带的尺寸。

**这段在干什么：** 把“我带你走”落实成可见动作。阿尔吉侬此后不再独立寻路，只作为查理头顶的陪伴对象。

**说完前先完成：** 阿尔吉侬跳上头顶。

### carry · `ch5.1.carry`

**触发：** 阿尔吉侬跳上头顶后。

**玩家状态：** 仍锁输入，直到 banner 结束。

**画面：** 阿尔吉侬已经停在查理头顶，并跟随查理移动。

**这段在干什么：** 确认两人此后同行。

**说完：** 解锁输入。玩家继续操作旋转机关，带着阿尔吉侬走向终点。

### 旋转故障

**触发：** 玩家拖动 `part_part_18` 期间，按每次拖动尝试抽样。

**玩家状态：** 正常机关操作，但可能失败。

**画面：** 可能出现拖动失灵、拖到一半回弹、或 Snap 变慢。失败不会提交非法 `yawSteps`，也不会刷新 Path Graph。

**这段在干什么：** 用玩法表现查理空间感知正在快速衰退。必须始终保留正确操作成功的可能。当前总故障概率约为 60%。

### finish · `ch5.1.finish`

**触发：** 查理到达终点，`level.finish` 被导演接管。

**玩家状态：** 锁输入、锁走路。

**画面：** 阿尔吉侬仍在查理头顶。关卡不再新增机关变化。

**这段在干什么：** 查理感慨刚才这段路比过去艰难得多，并决定在自己还能走的时候继续带阿尔吉侬走完剩下的路。

**说完：** 进入 5-2。

## 5-2 花园

关卡感觉：只剩一条真实存在的实体道路。没有可旋转机关，没有错视重构。查理顶着阿尔吉侬出发；走到半路，阿尔吉侬掉落到路面上，不再移动。

### 关卡开场

**触发：** 雾散、关卡稳定后，导演立即锁输入并播放 `ch5.2.intro`。

**玩家状态：** 锁输入、锁走路。

**画面：** 查理站在出生点。阿尔吉侬已经在他头顶。前方是一条没有错视机关的实体道路。

**这段在干什么：** 让玩家立刻看见查理能力已经衰退到只能看见实体路径，而阿尔吉侬仍是他仅剩的陪伴。

**说完：** 解锁输入和走路。

### intro · `ch5.2.intro`

**触发：** 进关后立刻播放。

**玩家状态：** 锁输入、锁走路。

**画面：** 查理顶着阿尔吉侬，面前只有真实道路。

**这段在干什么：** 查理确认错视联系已经从感知里消失。他知道自己衰退得很严重，但阿尔吉侬还在。

**说完：** 进入可玩状态。

### 掉落演出

**触发：** 查理抵达路径中段节点 `part_part_20:node_part_part_20_9`。

**玩家状态：** 锁输入、锁走路。

**画面：** 阿尔吉侬从查理头顶落到当前实体路径上，并停在该节点。查理不能再带着它继续走。

**这段在干什么：** 失去发生在陪伴途中，不做夸张死亡演出，也不再让研究员解释。

### loss · `ch5.2.loss`

**触发：** 阿尔吉侬落地后立刻播放。

**玩家状态：** 锁输入、锁走路。banner 播放期间玩家仍不能操作。

**画面：** 阿尔吉侬停在路径上，不再移动。查理独自站在它身边。

**这段在干什么：** 查理震惊、悲伤、遗憾。他意识到自己没能把阿尔吉侬带到花园。

**说完：** 解锁输入。玩家独自走向终点。阿尔吉侬留在掉落点。

### 关卡结束

**触发：** 查理到达 `finish_node`，现有完成触发器发出 `level.finish`。

**玩家状态：** 锁输入、锁走路。

**画面：** 阿尔吉侬仍停在中途路径上。终点不再重复播放失去台词。

**这段在干什么：** 失去已经发生。关卡结束只负责把查理送入墓地。

**说完：** 无额外台词。进入 5-3。

## 5-3 余光

关卡感觉：查理独自顶着一朵花，沿着逐段从黑暗里升起的真实道路走向墓碑。Tomb、grave 和后续路段一开始是纯黑并沉在 `y = -1`。花对齐选关筒花的尺度和颜色：白花瓣、黄花心、绿茎，没有高度雾。

### 关卡开场

**触发：** 雾散、关卡稳定后，导演立即锁输入，把 `StaticPath_2` 到 `StaticPath_8`、Tomb 和 grave 下沉并染成纯黑，再让查理头顶出现花，然后播放 `ch5.3.intro`。

**玩家状态：** 锁输入、锁走路。

**画面：** 查理站在出生点，头上顶着花。后续道路和墓碑尚未显现。

**这段在干什么：** 确认阿尔吉侬已经不在身边。查理的空间观测里只剩下自己，但他还记得要把花送到这里。

**说完：** `StaticPath_2` 从 `y = -1` 升到实际道路高度 `y = 0`，颜色从纯黑恢复为关卡配置色。随后解锁输入。

### intro · `ch5.3.intro`

**触发：** 进关后立刻播放。

**玩家状态：** 锁输入、锁走路。

**画面：** 只有出生点附近的路是可见的。花已经在查理头顶。

**这段在干什么：** 查理承认以后视野、视界和空间观测里只剩自己，但仍决定完成送花。

**说完：** 升起第一段隐藏道路，进入可玩状态。

### 逐段复原

**触发：** 玩家踏上当前可见路段后，下一段路升起。

**玩家状态：** 升起期间锁输入；升起完成后解锁。

**画面：**

```text
踏上 StaticPath_2 → 升起 StaticPath_3
踏上 StaticPath_3 → 升起 StaticPath_4
……
踏上 StaticPath_7 → 升起 StaticPath_8
踏上 StaticPath_8 → 升起 Tomb，grave 恢复配置色
```

路径从 `y = -1` 升到实际高度 `y = 0`，颜色从纯黑恢复为配置色。Tomb 和 grave 在最后一段升起时一起恢复。

**这段在干什么：** 真实道路在查理走近时才重新显现。这不是错视机关，也不恢复世俗世界，只让通往墓地的路一段段变得可走。

### 镜头拉近

**触发：** Tomb 和 grave 升起完成后，等待 1 秒。

**玩家状态：** 锁输入、锁走路。

**画面：** 相机缓慢拉近并聚焦墓碑。缓动是慢-快-慢，持续时间约 4.6 秒，比开场镜头更近。

**这段在干什么：** 把玩家的注意力从整条路收到墓碑前，为献花做准备。

### 献花

**触发：** 镜头拉近完成后。

**玩家状态：** 锁输入、锁走路。

**画面：** 花从查理头顶落到墓碑前。花保持选关筒花的颜色和尺度，茎底对齐墓前地面，不再漂在角色旁边。

**这段在干什么：** 完成约定。查理把花放下，而不是把阿尔吉侬救回来。

### offering · `ch5.3.offering`

**触发：** 花落到墓碑前之后。

**玩家状态：** 锁输入、锁走路。必须点完当前 modal。

**画面：** 花已经停在墓前。相机仍聚焦墓碑。

**这段在干什么：** 查理把花献给阿尔吉侬。这是第五章最后一句台词。

**说完：** 结束 5-3，进入章节结束流程。

## 三、导演实现边界

- 5-1 使用现有载鼠表现：`SetAlgernonCarried`。阿尔吉侬跳上头顶后停止独立寻路。
- 5-1 故障只作用于旋转 Part `part_part_18`。失败回弹不提交 `yawSteps`，也不刷新 Path Graph。
- 5-2 使用现有掉落表现：`DropAlgernonAt`。掉落后 Walker 停在实体路径节点上，不再移动。
- 5-3 使用现有携带静物表现：`SetCarriedStillObject` / `DropCarriedStillObject`。花不进入关卡静物树，也不成为 PathNode。
- 5-3 的下沉、升起和颜色变化是表现层。路径只在升起完成后提交实际高度并刷新当前有效 Path Graph。
- 5-3 没有现成 `finish_node`。关卡完成由献花台词结束后的 `FinishLevel()` 触发。

## 四、润色时的硬性边界

- 不要改变任何台词的 `id`、`mode` 或 `style`。
- 不要把 `modal` 改成 `banner` 或反过来，除非先确认演出节奏和输入锁定也要改变。
- 不要让研究员在第五章重新出现。
- 不要重新解释手术、实验或阿尔吉侬衰退时间线。
- 不要把 5-1 写成竞速或测试关；故障是衰退表现，不是惩罚。
- 不要把 5-2 的掉落写成夸张死亡、爆炸或突然消失。
- 不要让 5-2 结束后阿尔吉侬继续跟随查理。
- 不要把 5-3 写成能力恢复、世界恢复或城市重新有人。
- 不要把花改成关卡静物实例，或让花参与寻路。
- 不要把当前实现中的 API 名称、关卡 ID 或路径节点名改写成自然语言后再导回代码。
