# 《献给阿尔吉侬的花束》主题融入方案：多关卡错视解谜的轻叙事设计

## 文档定位

本文记录本项目围绕《献给阿尔吉侬的花束》进行的剧情与关卡线调研结论，以及基于当前“六边形纪念碑谷”玩法架构形成的设计方案。

本方案的核心前提是：

> 不是让故事驱动玩法，也不是把小说拆成一关；而是让多关卡玩法推动玩家逐步理解故事，让轻叙事为玩法提供方向、情绪和记忆点。

本文只描述剧情、关卡线和叙事—玩法关系，不规定具体脚本实现，也不替代当前 Path Graph、机关 Snap、固定相机和关卡数据架构文档。

---

## 一、设计结论摘要

### 1. 产品形态

项目应当是一个由多个独立视觉谜题组成的错视解谜游戏：

```text
章节
  -> 多个自包含关卡
    -> 观察固定相机下的空间
    -> 操作建筑机关
    -> 形成合法视觉连接
    -> 角色自动通过路径
    -> 关卡状态和叙事状态产生余波
```

它不是：

- 一关完成的文学寓言；
- 以文本为主体的视觉小说；
- 关卡之间插入长篇剧情的传统剧情游戏；
- 把智力、记忆或能力做成数值升级的游戏；
- 用每一个机关强行对应一个文学隐喻的符号解谜。

### 2. 叙事尺度

《献给阿尔吉侬的花束》需要缩略，但缩略的对象是剧情事件数量，不是玩家体验长度。

原著的复杂人生被压缩为：

```text
愿望
  -> 实验
  -> 清晰期
  -> 空城观测缺失
  -> 阿尔吉侬衰退
  -> 连接失效
  -> 送花
```

这条主线再展开成多个关卡，让玩家经历：

```text
无法到达
  -> 第一次形成错视连接
  -> 看见更多连接
  -> 手术完成，查理立即获得理解和创造建筑之间隐藏连接的能力；同时，城市中的世俗事物已无法进入他的空间观测
  -> 回到研究所询问原因
  -> 连接开始失效
  -> 给阿尔吉侬放花
```

因此最终作品不是“简化版小说”，而是：

> 一个借用《献给阿尔吉侬的花束》情绪脊骨的多关卡错视解谜游戏。

### 3. 叙事与玩法的耦合度

建议采用三层耦合，而不是强绑定。

#### 第一层：每关有叙事动机，但不解释谜题

玩家只需要知道：

- 为什么来到这里；
- 想去哪里；
- 完成后发生了什么变化。

谜题规则由玩家观察建筑、机关和角色行动自行理解。文本不解释“这座旋转塔代表查理的大脑”，也不解释“这两条投影边为什么能连接”。

#### 第二层：章节变化由玩法结果推动

玩家完成一组空间问题后，世界状态发生变化：

- 研究所打开；
- 新的建筑区域出现；
- 远处的道路变得可达；
- 手术完成后，城市中的世俗事物已经从查理的空间观测中缺席；
- 阿尔吉侬在后续章节出现衰退，借来的道路逐渐失效；
- 查理最终回到真实道路。

剧情变化来自关卡完成后的状态，而不是来自独立于玩法之外的剧情系统。

#### 第三层：少数关键转折真正改变玩法

适合进入玩法的转折只有少数几个：

1. 无法通过普通道路；
2. 获得一种新的“看见连接”的方式；
3. 手术完成后，城市中的世俗事物已经从查理的空间观测中缺席，只剩下泡在雾里的建筑；
4. 阿尔吉侬在后续章节出现衰退，借来的道路逐渐失效，最后回到真实道路。

面包店同事、母亲、妹妹、学术会议、恋爱关系等内容可以合并为环境、短文本或剪影，不必逐一变成新的关卡系统。

## 二、当前项目玩法基础

本方案建立在现有项目文档定义的玩法目标上。

### 1. 项目目标

项目是“六边形纪念碑谷”式错视解谜游戏。三棱柱体素、Part、Object Tree 和局部体素编辑器服务于关卡制作、白盒搭建和运行时 Debug，不是最终产品方向。

核心玩法闭环是：

```text
固定正交视角观察建筑
  -> 玩家操作六向建筑机关
  -> 建筑状态改变视觉对齐关系
  -> 固定相机下出现新的视觉连接
  -> 当前有效 Path Graph 生成新边
  -> BFS 寻路
  -> 小人自动走到目标
```

当前最小验证场景是：

```text
起点平台 -> 中央六向旋转结构 -> 目标平台
```

旋转前不可达，旋转后通过错视连接可达。

### 2. 玩家核心循环

```text
观察固定视角下的建筑
  -> 看见一个可见但不可达的目标
  -> 观察机关与道路端点
  -> 拖动建筑机关
  -> Snap 到合法离散状态
  -> 固定相机下视觉连接成立
  -> 当前有效 Path Graph 刷新
  -> 点击目标
  -> 小人自动沿路径抵达
```

游戏过程不是自由控制角色，而是让玩家通过建筑操作改变角色可走的路径。

### 3. Path Graph 的职责

当前有效 Graph 由以下信息派生：

```text
局部 PathNode
  + Level 候选连接
  + Part 当前 Transform
  + 合法 Snap 状态
  + 固定游戏相机
  -> PathRuntime
  -> CurrentEffectiveGraph
  -> BFS / Character
```

寻路只消费当前有效 Graph。角色、Mesh、Scene Node 和物理碰撞不能反向定义关卡连接。

### 4. 视觉连接的基本语义

跨 Part 的错视连接满足：

```text
两个候选可走面
  -> 应用各自 Part Transform
  -> 使用固定游戏相机投影
  -> 对应面边共线且正长度重合
  -> 重合接缝没有更近逻辑体素面遮挡
  -> 形成 accepted visual edge
```

因此：

- 真实空间不必相接；
- 面不必共面；
- 法线不必相同；
- 只有端点接触不算连接；
- 深度差不能替代投影边重合；
- 遮挡证据不足时不能自动通过；
- 更近的逻辑体素面切断接缝时应拒绝连接。

### 5. 机关状态边界

机关采用离散 Snap 状态：

```text
rotatorStep = 0..5
```

动画中只更新表现层 Transform，不更新玩法 Graph。Snap 完成后才提交离散状态、重新评估视觉候选并原子替换当前有效 Graph。

这条边界对叙事也很重要：

> 只有玩家真正完成一次建筑理解，世界才确认新的道路；半旋转不是故事状态，也不是玩法状态。

## 三、纪念碑谷三部曲的叙事与关卡调研

本节总结对《Monument Valley》1、2、3 的外部调研。以下内容区分“较高可信度事实”和“设计归纳”。

### 1. 共同结构

三部作品并不是先写出完整剧情，再用关卡承载剧情；更接近于：

> 先建立一个可感知、可操作的空间体验，再让角色目标、机关变化和环境变化承担叙事功能。

三部作品共同采用：

1. 文本极少，故事主要由空间、角色动作、色彩、音乐和机关变化表达；
2. 每个关卡既是一个谜题，也是一个独立的视觉与情绪段落；
3. 章节不是传统剧情任务链，而是由“新机制—变体—高潮展示—情绪留白”组成的体验序列；
4. 角色与机关的关系会随叙事主题变化；
5. 玩法表达的不是具体剧情细节，而是关系状态、情绪转折和主题隐喻；
6. 可理解、可完成、低挫败优先于持续堆叠高难度；
7. 关卡结尾通常提供视觉句号，而不是完整解释世界观。

### 2. 第一部：空间、宽恕与归还

《Monument Valley 1》的官方产品描述包含“A Quest for Forgiveness”，即“寻求宽恕的旅程”。玩家引导沉默的公主穿越神秘纪念碑，操纵建筑、创造路径并揭示隐藏空间。

较高可信度的设计事实包括：

- 游戏受到 M.C. Escher 不可能几何的启发；
- 团队不希望只制作传统意义上“有挑战的谜题”；
- 目标偏向审美和情绪体验；
- 每个画面应当像一件独立的艺术品；
- “短而 sublime”是有意的体验策略。

其叙事主要由以下元素承担：

| 关卡元素 | 叙事作用 |
|---|---|
| 神圣、空旷、带有仪式感的建筑 | 建立古老文明、失落秩序和神秘感 |
| 角色在不同纪念碑之间持续前进 | 形成旅程结构 |
| 隐藏路径被揭开 | 将发现真相转化为操作行为 |
| 破碎、封闭或循环空间 | 暗示失序、阻隔与过去的负担 |
| 机关重新连接、建筑恢复运作 | 让修复和归还成为可见结果 |
| 结尾仪式空间和色彩变化 | 提供情绪收束，而不是解释所有历史 |

重要判断：

- 事实是游戏的主题包含宽恕，关卡围绕穿越纪念碑、寻找路径和完成仪式性目标组织；
- “玩家通过把不可行走空间变成可行走空间，体验从混乱走向秩序”是合理的设计推断，而不是每个机关都对应某个具体剧情事件。

### 3. 第二部：母女关系直接变成操作关系

《Monument Valley 2》围绕母亲 Ro 和她的女儿展开。它是三部作品中叙事与机制结合最明确的一部。

可确认的结构包括：

- 玩家同时接触母亲和女儿；
- 早期母女可以作为一个整体移动；
- 后续通过破碎通道等空间变化将两人分开；
- 女儿拥有跟随、独立行动和参与机关的阶段变化；
- 某些谜题要求两个角色分别站到机关位置或互相打开通路；
- 游戏主要使用色彩、关卡设计、机制变化和角色动作，而不是传统对白表达关系。

其关系结构可以分成四阶段：

#### 阶段一：共同移动

母亲和女儿作为一个行动单位。玩法表达依赖和引导，玩家实际负责带着孩子前进。

#### 阶段二：空间分离

道路断裂或区域分开，玩家不能再把母女当作一个整体。空间距离直接被体验为关系变化。

#### 阶段三：互相协作

两个角色分别操纵不同机关，女儿从被带领的对象变成谜题链条中的主动节点。亲子关系从单向照顾转为互相支持。

#### 阶段四：独立行动与重新连接

女儿获得独立解决问题的能力，关系从依赖转为支持。目标不是永远绑定，而是在不同路径成长后再次连接。

### 4. 第三部：光、灯塔、自然与环境危机

《Monument Valley 3》的主角是灯塔学徒 Noor。其世界包含光明消退、灯塔、水域、船、上涨的水域以及建筑与自然的冲突。

开发者资料强调了一个重要变化：

> 在前两部中，建筑是主要角色之一；第三部希望让自然也成为重要的叙事和设计对象。

可借鉴的结构包括：

| 机制或环境 | 叙事功能 |
|---|---|
| 灯塔 | 世界秩序、社区安全和持续性的中心 |
| 光 | 资源、希望和恢复目标 |
| 船 | 从封闭纪念碑走向更大环境 |
| 上涨水域 | 让环境危机具备空间和视觉即时性 |
| 植物与建筑融合 | 让自然成为关卡参与者 |
| 城市与自然碰撞 | 让空间承载环境主题 |

媒体将其解读为环境主义、气候迁移或“希望朋克”，但这些属于评论性阐释，不能全部当作开发者明确的剧情定义。

### 5. 纪念碑谷的关卡组织

更可靠的组织方式不是固定关卡数量，而是关卡体验节奏：

```text
引入
  -> 机制变体
  -> 关系或主题变化
  -> 视觉高潮
  -> 缓冲或留白
```

关卡往往是独立的视觉短篇：

1. 用一个清晰画面提出问题；
2. 让玩家学习空间规则；
3. 通过变体打破预期；
4. 在结尾用视觉变化完成高潮；
5. 让角色动作或环境状态提供收束。

其节奏重点是“惊喜密度”而非单纯难度：

- 更换空间形态；
- 引入新的视觉规则；
- 让同一机关产生不同含义；
- 增加角色之间的空间依赖；
- 将局部空间扩展成多个层次；
- 让玩家在熟悉规则后看到更大的视觉结果。

### 6. 纪念碑谷调研的直接借鉴

对本项目最重要的不是复制具体机关，而是复制职责分工：

- Path Graph 是当前有效连接的计算结果，不是玩家要阅读的叙事对象；
- 每个章节围绕一种空间命题；
- 机关状态可以承担情节转折；
- 角色应成为路径变化的见证者；
- 关卡结束时让建筑、角色或环境状态发生可见变化；
- 轻叙事不等于没有主题，而是不把主题全部写成说明。

## 四、独立游戏“叙事服务于玩法”的调研

### 1. 三种关系

#### 类型一：叙事为玩法提供动机

叙事回答：

- 为什么我要去那里？
- 为什么我要观察这个物件？
- 为什么这个空间值得重新理解？
- 为什么我愿意继续尝试？

《Outer Wilds》是典型案例：玩家不是依赖传统任务列表和装备升级，而是因为新的问题、新的线索和新的世界规律继续探索。

#### 类型二：玩法表达叙事主题

主题不只写在对白里，而是出现在玩家反复执行的行动中。

相关案例包括：

- 《Celeste》用反复尝试、失败、坚持和对抗内在自我表达心理挣扎；
- 《Gorogoa》用拼接、重叠和重新理解视觉关系表达记忆、时间与破碎经验；
- 《What Remains of Edith Finch》让不同家庭成员拥有不同的操作方式，使生活方式和死亡方式直接成为可玩体验；
- 《Monument Valley》让空间规则承担情绪和关系表达。

#### 类型三：玩法产生叙事解释

玩家先遇到系统现象，再逐渐建立世界观解释。

相关案例包括：

- 《The Witness》先让玩家理解图形规则，再让玩家意识到岛屿、建筑、声音和符号之间存在更大的关系；
- 《Outer Wilds》先经历时间循环和空间变化，再拼出宇宙历史；
- 《Return of the Obra Dinn》先观察人物、空间和死亡场景，再通过调查构建事件真相。

本项目最适合结合类型一和类型二，并适度使用类型三：

```text
故事给玩家一个想去哪里的理由
  -> 玩家通过操作建筑产生实际理解
  -> 玩家从空间结果推断查理经历的变化
```

### 2. 信息粒度

叙事信息应匹配玩家当前行动，不要一次解释完整故事。

#### 层级 A：即时操作信息

回答：

- 这个机关能不能操作？
- 这段路能不能走？
- 这两个区域是否存在连接？

优先用视觉、声音、动画和空间布局表达。

#### 层级 B：局部因果信息

回答：

- 为什么这条路断开？
- 为什么机关改变后道路成立？
- 为什么两个空间可以连接？

最好通过玩家操作后的结果表达。

#### 层级 C：区域或章节信息

回答：

- 这里发生过什么？
- 这个空间属于谁？
- 这一章的情绪是什么？

可以用少量文本、环境陈设、角色反应和视觉主题表达。

#### 层级 D：世界背景信息

包括历史、家族、实验背景和社会环境。这类信息不应阻塞当前玩法，可作为可选阅读、隐藏线索或后续重解释。

### 3. 关卡作为叙事单元

每个关卡可以被视为一个完整叙事段落：

```text
建立当前状态
  -> 玩家看见异常
  -> 玩家形成局部假设
  -> 玩家操作空间或机关
  -> 视觉连接或逻辑关系成立
  -> 玩家获得路径、信息或情绪结果
  -> 下一关继承新的问题
```

适合空间错视游戏的“叙事动作”包括：

- 对齐两个原本分离的结构；
- 将角色送到一个不可能到达的地方；
- 旋转空间后发现旧路径；
- 让一个机关从障碍变成桥梁；
- 将物件放回原位；
- 复原一个被破坏的结构；
- 通过不同空间的相似布局推断历史联系。

### 4. 机制引入、变奏与组合

机制引入建议遵循：

```text
展示规则
  -> 安全尝试
  -> 一次直接使用
  -> 改变一个变量
  -> 要求玩家迁移理解
```

机制变奏应保持一个核心不变量，只改变对象、时机、空间关系或叙事语境。

组合应遵循：

```text
机制 A 单独教学
  -> 机制 B 单独教学
  -> A/B 并列但互不干扰
  -> A/B 产生相互影响
  -> A/B 在叙事上产生新含义
```

推荐给每关写一句“玩法句子”：

```text
玩家通过改变 X，使 Y 成为可达状态，
从而理解 Z。
```

例如：

```text
玩家通过旋转中段塔体，
使两条不连续的楼梯在固定视角下重合，
从而理解这个世界的道路不是由物理连续性决定，而是由视觉连接决定。
```

### 5. 失败和重试

本项目不需要传统死亡。空间解谜可以使用软失败：

- 角色走入死路；
- 机关进入不可用状态；
- 视觉连接短暂成立但无法通行；
- 玩家发现一种假设不成立；
- 空间状态需要重置。

失败至少应有一种价值：

1. 提供规则信息；
2. 缩小解空间；
3. 建立情绪意义。

对本项目而言，失败应暴露错误的连接假设，例如：

- 玩家以为两段路在所有状态都相连，但角色走到边缘后停住；
- 玩家以为机关只影响当前空间区域，但远处道路也发生变化；
- 玩家以为视觉重合就是逻辑可达，但接缝被遮挡；
- 玩家以为某个 Snap 合法，但证据不足，连接不被 Graph 接受。

重试应快速，不重复已经没有价值的动画和长路径。

### 6. 角色关系如何不抢玩法

最有效的角色关系不是让角色长时间谈论关系，而是让玩家操作关系本身。

可用的关系机制包括：

- 一个角色改变另一个角色的可达路径；
- 两个角色必须保持某种空间关系；
- 玩家决定谁先通过、谁留下；
- 角色移动方式表达性格；
- 角色对空间变化产生不同反应。

但角色关系不能成为第二套竞争玩法。应遵守：

- 对话不解释玩家已经看见的内容；
- 关系变化必须改变下一次行动，或至少改变玩家对空间的理解；
- 角色信息分散在移动过程中，保留留白；
- 先让玩家“做过”，再让角色“说出一点”。

### 7. 文本、语音与过场边界

建议表达优先级：

```text
空间关系
  > 角色行动
  > 机关反馈
  > 环境声音
  > 短文本或语音
  > 完整过场
```

文本适合表达：

- 精确名称、地点和人物关系；
- 无法从环境可靠看出的历史信息；
- 章节之间的连接；
- 已经体验过但还没有完全理解的情绪背景；
- 可选的深层背景。

文本不适合：

- 复述玩家刚刚看到的机关结果；
- 解释每个机关的象征意义；
- 替代角色动作；
- 频繁打断操作。

过场适合表现时间跨度、无法直接交互的历史事件、章节状态切换和关系结束，但过场之后必须产生可操作回声：

- 新的空间状态；
- 新的可走面；
- 新的机制约束；
- 新的角色关系；
- 新的玩家问题；
- 对旧空间的重新解释。

## 五、原创游戏的总体剧情线

### 1. 故事核心

本项目不直接复制原作的“智商提升”结构，而将其转换为更贴合错视解谜的核心命题：

> 查理看不见不可能的路径，因此来到实验室寻求帮助。

在此基础上，认知重构带来两个同时完成、但不能简单等同于“变聪明”的结果：

> 查理获得理解和创造错视路径的能力；手术完成的同一时刻，城市中的世俗事物也从他的空间观测中缺席。

这里的“世俗事物”包括行人、车辆以及道路上的日常物件和活动痕迹。下文将这种变化简称为“观测缺失”。“观测缺失”不是肉眼视力，也不是查理是否关心别人，而是这些普通生命、物件与活动无法被他确认并纳入正在理解的空间关系。它在手术完成后立即成立；第三章不是观测能力逐渐衰退的过程，而是查理在城市中逐步发现、验证并确信自己无法观测到世俗世界的过程。到第四章，他回到研究所询问这种变化；阿尔吉侬的衰退在此后才成为另一条叙事线。

这里需要保留一个表现边界：查理在第四章仍然可以听见研究员的声音，但看不见、也无法定位研究员的身体。研究员可以在研究所内部实际存在，也可以通过实验室内部通话或画外声音参与叙事；“声音来自喇叭”只能是查理此前的误解，不能写成客观设定。第三章的城市不安排任何可定位的旁人、旁人活动或相关声音，避免用对白抵消“空城感”。

1. 查理能记得自己的名字、工作和生活，却看不见建筑中不可能的路径；
2. 他来到实验室，是为了获得看见这些路径的帮助；
3. 阿尔吉侬是第一、二章中的先行者和空间对照对象；
4. 认知重构让查理在手术完成后立即获得理解和创造错视路径的能力，同时让城市中的世俗事物从他的空间观测中缺席；
5. 城市中的世俗世界从查理的空间观测中缺席，他因此回研究所询问原因；
6. 第四章固定为四关，按 4-1 悬念、4-2 目击、4-3 交锋、4-4 闭合的节奏展开；
7. 研究员在第四章结尾明确解释手术问题和阿尔吉侬衰退的时间线，查理承认自己急于改变而选择手术，并决定陪伴阿尔吉侬；
8. 查理最后沿真实道路走到阿尔吉侬那里，放下一束花。

这里的“看见”不是视力，也不是普通意义上的聪明，而是对错视空间关系的理解，以及对生命和世俗活动能否进入当前空间观测的确认能力。它不应被做成数值、技能树或永久能力条。

这些内容足够构成完整游戏叙事，同时把人物主题、关卡空间和视觉表现放进同一条主轴。

### 2. 故事脊骨

```text
查理记得自己是谁，却忘了为什么来到这座陌生的实验室
  -> 他看见迷宫和门，决定先走到门那里，也许能想起更多事情
  -> 他看见阿尔吉侬飞过不可能的路径
  -> 研究员告诉他：他来这里，正是因为看不见这样的路
  -> 手术完成，查理立即获得理解和创造建筑之间隐藏连接的能力；同时，城市中的世俗事物已无法进入他的空间观测
  -> 他离开实验室，进入一座仍然有人生活、但在他的空间观测中呈现为空城的城市
  -> 3-1 到 3-3：查理逐步发现、验证并确信自己无法观测到行人、车辆、日常物件和活动痕迹
  -> 3-4：查理下定决心回实验室问清楚
  -> 4-1：查理回到研究所，在空实验室中听见隔壁异常测试的断续声音
  -> 4-2：查理目击阿尔吉侬由异常敏捷变为迟疑和停滞，研究员暂时归因于疲劳
  -> 4-3：查理说明自己看不见世俗，并在一次集中交锋后迫使研究员正视问题
  -> 4-4：研究员明确解释手术问题和阿尔吉侬的衰退时间线
  -> 查理承认自己当初急于改变而选择了手术，接受代价并决定陪伴阿尔吉侬
  -> 错视路径和对世俗世界的观测逐步退去，查理沿真实道路走到阿尔吉侬那里
  -> 他放下一束花
```

这条脊骨把三种失去分成三个阶段：

```text
第三章：先经历世俗世界从空间观测中缺席
第四章：再失去阻止阿尔吉侬衰退的可能
第五章：最后失去错视路径，但保留感情与行动
```

玩家不会在第四章开场听到完整解释，而是先通过空实验室中的断续声音和阿尔吉侬的迟疑目击异常，再由 4-3 的一次集中交锋把两条悲剧汇聚为同一个问题，最后在 4-4 获得明确说明并完成接受。这样既保持“先体验空间，再理解人物”的叙事方法，也避免把争吵或反复求解贯穿整个章节。

### 3. 不应做的叙事误读

不要把：

- 第三章使用“高峰”或“孤独高处”的标题和主题；
- 让查理在城市里寻找阿尔吉侬；

```text
旋转机关 = 聪明
视觉连接 = 智商
连接失效 = 查理受到惩罚
Path Graph = 查理的心理状态
```

作为一一对应的硬编码隐喻。

更合适的关系是：

> 玩家在不断重新理解空间；查理也在不断重新理解自己所处的世界。空间经验与人物经历产生共振，但不强行规定唯一解释。

### 4. 关于“看见不可能的路径”的表达

本项目用“能否看见不可能的路径”替换原作中“智商高低”的叙事位置。这个转换不是把错视能力当成新的智商数值，而是把查理的困境直接放进游戏的空间语言里：

- 查理能确认门，却无法理解通往门的某些空间连接；
- 查理能记得自己的名字、工作和生活，却不一定能理解当前这座建筑；
- 实验不是让他变成“更有价值的人”，而是帮助他理解原本无法确认的空间关系；
- 看见更多空间关系不等于生活变得更好，新的道路也可能带来距离、误解和失去；
- 后期路径逐渐消失时，表现的是能力和世界关系的变化，不是对查理的人格进行惩罚。

不建议：

- IQ 数值；
- 技能树；
- 直接解锁“聪明等级”；
- 用操作速度或移动能力体现人物价值；
- 后期故意让玩家操作变慢或变笨；
- 让“看见路径”成为一种可以永久拥有、脱离剧情代价的装备。

推荐通过以下方式表达变化：

- 关卡中可理解的空间关系逐渐增多；
- 城市中的世俗事物从查理的空间观测中逐渐缺席，但这不是普通人的实际消失；
- 阿尔吉侬在前后章节承担先行者、对照和情感连接，第三章不出现；
- 研究所环境从陌生、封闭变成高耸、开放，再回到需要面对的实验现场；
- 关卡从局部固定边扩展到更多视觉候选边，再逐渐回到真实固定边；
- 查理从依靠熟悉的生活记忆行动，变为主动观察空间关系；
- 文案从具体、断续的自我记录，逐渐变得完整、精确，再出现遗忘和简化；
- 旧连接后来逐步失效。

“温情在，理智不在”可以作为第一章的美术感受，但应具体理解为：

> 生活记忆和情感仍在，对空间的判断以及对当前处境的理解暂时缺席。

因此，第一章的暖黄不是客观世界的真实色彩，而是查理残留的生活感和安全感。建筑可以陌生、封闭、难以理解，画面的色彩却保留温度。后续章节再通过色彩、空间开合和路径数量的变化，让玩家感到“看见”逐渐发生，而不需要用台词宣布能力升级。

## 六、多章节、多关卡设计方案

建议设计为五章、18 关，按 3-4-4-4-3 排布。如果第一版需要收敛，可以压缩为四章、12 关。章节数不是必须一次性实现的内容，而是完整剧情线的规划骨架。

### 章节一：跑不过的迷宫（进入实验室）

#### 剧情功能

第一章不急着介绍实验，也不让研究员替查理解释来历。查理已经进入实验室，但他暂时想不起自己为什么在这里。

他仍然记得一些贴近生活的事情：自己的名字、在面包店的工作、回家的路，以及一种说不清的安心感。可是，当他面对实验室里的建筑时，这些记忆不能帮助他理解当前的空间。

第一章的叙事核心是：

> 查理记得自己是谁，却忘了自己为什么来到这里。他看见门，于是决定先走到门那里，也许门后会有答案。

第一关不出现阿尔吉侬，也不出现研究员。查理的主观声音承担 1-1 的全部叙事，玩家和他一起在陌生环境中寻找方向。第二关开始，阿尔吉侬和研究员再进入叙事。

#### 第一章的主观色彩

第一章的暖黄不是实验室客观意义上的颜色，而是查理残留的生活感和安全感。环境对他来说是陌生、难以判断的，画面却不能因此变成冷漠的黑白：

```text
生活记忆还在
情感和温度还在
对空间的判断暂时缺席
```

因此，第一章可以同时拥有陌生的建筑和温暖的色彩。色彩不是“世界在安慰他”的客观叙述，而是查理仍带在身上的感受。

#### 文案声部与沉浸原则

1-1 只使用查理的声音，包括面向环境的说话和只属于他的内心独白。不使用研究员，不使用第三者旁白，也不使用系统式剧情说明。第二关开始，研究员才在查理亲眼看到阿尔吉侬之后进入叙事。

文案不应像人物档案一样一次性介绍查理，而应像他在陌生地方进行一份不完整的自检：

```text
查理看见陌生环境
  -> 试着确认自己记得什么
  -> 发现自己忘了来这里的目的
  -> 看见一扇门
  -> 决定先走到门那里
```

推荐的语言原则：

1. 先写眼前的东西，再写抽象的疑问；
2. 用生活细节证明“我是谁”，不要用履历介绍人物；
3. 记忆空白只落在“为什么来到这里”，不要写成完全失忆；
4. 门是查理自己选出的线索，不是系统替他指定的目标；
5. 文案只提供动机和情绪，不解释迷宫规则。

#### 三关安排

| 关卡 | 玩法与表现 | 叙事作用 |
|---|---|---|
| 1-1 雾中盲途 | 查理从下方升入一座静态迷宫，沿已有道路观察和行走，前方只有一扇门 | 建立实验室的陌生感，完成“我是谁、我记得什么、我为什么在这里”的局部自检 |
| 1-2 虚空足迹 | 查理在迷宫中前进，看到阿尔吉侬飞跃一条自己无法通过的不可能路径；研究员在此时第一次回应 | 让玩家先看到查理与阿尔吉侬的差异，再由研究员补回查理来实验室的来意 |
| 1-3 错位之契 | 研究员让沟壑所在的 Part 被动旋转，使原本断开的道路在固定视角下连接 | 查理第一次在实验中走过不可能的路径，第一章从“寻找来意”进入“接受帮助” |

#### 1-1：雾中盲途

1-1 是查理进入实验室后的第一段可操作记忆。不要表现成他从实验室外走进来，而是让空间像一座刚刚被他发现的房间一样，在他脚下升起。

推荐的演出顺序：

```text
玩家进入关卡
  -> 查理和角色都保持锁定
  -> 迷宫从 y=-2 升到 y=0
  -> 升起完成后，查理开始自检
  -> 开场 modal 结束
  -> 查理获得行动许可
  -> 玩家引导查理走向门
  -> 查理真正开始寻路五秒后，出现一条短暂的内心 banner
  -> 查理抵达门，播放结尾 modal
```

开场自检的内容顺序应当是：

```text
这是哪里？
我叫查理·戈登。
我在面包店工作。
这些我还记得。
可我想不起自己为什么会在这里。
```

最终不要由旁白总结“查理失忆了”，也不要让查理马上说出“我来实验室是为了看见不可能的路径”。这个目的应留到第二关由阿尔吉侬的行动和研究员的回应补回。

门的动机应保持个人化、暂时性和不确定：

```text
前面有一扇门。
门后面比这里亮。
我先去那里看看。
也许到了那里，我就能想起来。
```

这里的“去门那里”不是对玩家下达任务，而是查理在记忆断裂后做出的第一个朴素决定。玩家的引导行为因此自然成为帮助查理寻找记忆，而不是执行一个抽象的关卡目标。

1-1 不加入：

- 阿尔吉侬；
- 研究员对白；
- 旋转机关；
- 错视连接教学；
- 竞速或失败惩罚；
- 直接解释“看见不可能的路径”的实验设定。

#### 1-1 的文案尺度

开场 modal 不宜超过四个短段，过程中 banner 只在查理已经开始行动后出现一次或极少出现。抵达门后的 modal 只确认“他到了”和“门后有某种熟悉感”，不要在第一关结尾揭开实验真相。

建议的情绪落点不是“查理成功走出了迷宫”，而是：

> 他走到了门前，但还没有想起自己为什么来。

#### 1-1 结束时

1-1 结束时，玩家应只获得这些信息：

```text
查理叫查理·戈登
他在面包店工作
他记得自己的生活，却忘了此刻的来意
他看不懂这里的路
他相信门后可能有答案
```

玩家还不知道：

```text
实验具体是什么
谁把查理带到这里
阿尔吉侬是谁
为什么有些路径是不可能的
```

这些未知应成为下一关的进入动力，而不是第一关的说明文字。

---

### 章节二：打开的世界

#### 剧情功能

第二章从第一关留下的疑问开始，而不是重新开一个实验说明。第二关中，查理先看到阿尔吉侬飞跃一条自己无法通过的不可能路径；研究员在这个结果之后第一次说话，并告诉他：查理来到实验室，正是因为看不见这样的路。

研究员不是开场讲解者，而是对玩家已经亲眼见到的结果做出现实层面的回应。查理也不是在听课，而是在看到阿尔吉侬之后，逐渐想起自己为什么站在这里。

#### 玩法重点

第二章开始引入不可能路径和错视连接：

- 阿尔吉侬可以飞过查理无法通过的空间断裂；
- 查理第一次明确意识到，自己看见的世界和阿尔吉侬看见的世界不一样；
- 研究员通过一次被动演示，让查理看到建筑关系可以改变；
- 后续关卡再把被动展示的空间关系交给玩家操作。

#### 关卡安排

| 关卡 | 玩法 | 叙事作用 |
|---|---|---|
| 2-1 盲点重塑 | 阿尔吉侬沿路径前进并飞过查理无法越过的沟壑，查理只能走向另一扇门 | 让玩家先看到差异，再产生疑问 |
| 2-2 编织空间 | 查理主动旋转建筑，创造一条原本不存在的视觉连接，并亲自走过它 | 从“看见连接”推进到“创造连接”，建立主动操作的能力感 |
| 2-3 独行的轨迹 | 阿尔吉侬和查理在复杂滚筒空间中共同探索，查理逐渐形成自己的路线判断 | 让查理摆脱单纯模仿，开始建立独立判断 |
| 2-4 高处的告别 | 查理独立找到 Lift 出口，作出离开实验室的选择，并与研究所暂别 | 完成第二章的能力收束，留下与阿尔吉侬分别及未来回访的情感动机 |

第二章的叙事顺序必须保持：

```text
先看见阿尔吉侬行动
  -> 查理产生惊讶或比较
  -> 研究员回应
  -> 玩家通过建筑变化验证回应
```

不能反过来先由研究员宣布查理缺少什么，再让玩家寻找例证。那会重新变成“为了交代而交代”。

#### 第二章的研究员

研究员第一次说话时，台词应当像回应查理刚刚看见的事情，而不是面向玩家的说明书。他可以补上查理想不起的事实，但不应把错视机制讲成教程：

```text
查理：它刚才过去了。
研究员：是的。
查理：我为什么不行？
研究员：因为你还看不见那条路。
查理：所以我才来这里？
研究员：你自己要求来的。
```

最后一句只确认查理的来意，不解释实验原理。真正的答案由后续建筑变化给出，而不是由研究员继续解释。

### 章节三：空城（城市）

#### 剧情功能

第三章是查理离开研究所后的城市探索篇。城市仍然存在，也仍然有人生活，但查理在手术完成后就已经失去对世俗世界的观测能力；3-1 到 3-3 的变化不发生在能力本身，而发生在查理对这一事实的认识上。他在探索中逐步确认：行人、车辆、道路上的日常物件以及旁人的活动痕迹都无法进入他的空间观测，只能感受到泡在雾里的建筑，因此城市在他的经验中成为一座空城。

本章的核心不是“查理站得比别人高”，也不是“城市里的人真的消失”，而是：

> 建筑仍在，世俗世界却无法进入查理的空间观测。

3-1、3-2、3-3 不安排阿尔吉侬、研究员或任何可定位的旁人。三关都由查理独自探索；观测缺失在手术完成时已经成立，三关通过不同层次的空旷建筑、雾、缺失的日常物件和持续没有回应的城市空间，让查理逐步发现、验证并确信这一事实。玩家不被要求寻找隐藏人物；“空城”是查理的观测结果，不是一个寻人谜题。

第三章结束时，查理仍然没有得到解释。他只是越来越确定：问题不只是无法确认人物，而是整个世俗世界都无法被自己观测到。因此他在 3-4 下定决心回到研究所，向研究员问个清楚。

#### 空间环境

第三章四关全部发生在同一座城市的不同区域，不在中途插入研究所。建筑泡在雾中，城市尺度逐渐扩大，但行人、车辆、路边物件、生活设施的活动痕迹和声音都不进入查理的空间观测。环境应表现“生活曾经存在过”与“当前无法被确认”之间的落差。

城市的色彩延续第二章 Lift 后建立的冷蓝灰，并逐步增加雾、开阔天空、远处楼群和空旷街道的比例。色彩表达的不是城市很美，也不是单纯的孤独，而是手术后立即形成的观测缺失在城市环境中的持续显现：空间清晰，世俗世界无法被确认，且始终没有回应。

#### 玩法重点

第三章继续使用已经建立的错视路径，不新增“观测世俗世界”的独立操作系统。空间规则逐渐复杂，但玩家操作保持稳定：

- 视觉候选边增多，城市中的道路呈现更多层次；
- 远处目标清晰可见，但世俗物件和活动不进入当前空间观测；
- 建筑和道路可以被理解、旋转和连接；
- 空城通过空场、雾、生活空间的遗留布局和缺失的活动表现；
- 三关中不出现阿尔吉侬；
- 3-4 的回研究所决定来自查理对空城现象的确认，而不是来自阿尔吉侬事件。

玩家不应被要求在空城中寻找隐藏人物。这里的“看不见人”以及“观测不到世俗世界”是查理的空间认知结果，不是需要破解的寻人谜题。

#### 关卡安排

第三章共 4 关，前三关是查理独自进行的城市探索；3-4 用于让他下定决心回到研究所。前三关的具体关卡内容不在本文预先规定，由实际关卡制作决定。

```text
进入城市
  -> 发现没有行人
  -> 发现没有车辆和道路上的日常物件
  -> 发现连活动痕迹也无法被观测
  -> 越来越确定情况不对
  -> 3-4 决定回研究所问清楚
```

### 章节四：回返与承认（研究所）

#### 剧情功能

第四章全部发生在研究所内部，并按与第二章相反的方向依次重返旧实验空间：

```text
4-1 复用 2-4 的出口与 Lift 空间
  -> 4-2 复用 2-3 的滚筒寻路测试空间
  -> 4-3 复用 2-2 的空间联系训练空间
  -> 4-4 复用 2-1 的手术与最初测试空间
```

同一组空间在第二章代表能力打开，在第四章代表回返、异常与承认。第四章固定为 4 关，不增加额外关卡；每关只承担一个主要叙事任务：

```text
4-1 悬念：空实验室与隔壁断续传来的异常测试词语
4-2 目击：阿尔吉侬不再敏捷，研究员暂时解释为疲劳
4-3 冲突：查理说明自己看不见世俗，研究员发现查理一直看不见自己
4-4 闭合：研究员完整解释手术问题和衰退时间线，查理接受当初自己的选择
```

第四章必须同时闭合两条悲剧线：

1. 查理告诉研究员，自己从手术完成后就只能感知建筑、道路和隐藏连接，无法观测行人、车辆、日常物件、旁人活动痕迹和城市生活回应；
2. 研究员告诉查理，阿尔吉侬在手术前和查理离开研究所时都没有出现明确副作用，是在查理离开后才在日常寻路测试中逐渐出现停滞、重复判断和无法通过熟悉路径的衰退。

研究员不能在 4-1 或 4-2 轻易说明真相。4-3 只承担全章唯一一次集中交锋：查理说出自己看不见世俗，研究员被迫正视问题，并同意回到最初的手术记录。4-4 不再争吵，由研究员明确说明手术问题和阿尔吉侬衰退的时间线，查理承认自己的选择并完成接受。

4-4 必须完成信息和情绪闭环。研究员明确说明：手术重构了查理的空间观测，使他获得感知和建立隐藏连接的能力，同时失去了对世俗生活的稳定接收；阿尔吉侬的衰退属于同一实验风险链中后来被确认的问题。查理承认当初在手术与不手术之间因急于改变而选择了手术，接受结果，不再和研究员争吵。接受不等于放弃；他决定陪伴阿尔吉侬走完还能走的路，为第五章的纪念线建立动机。

第四章的核心不是查理突然变笨，也不是研究员与查理持续争吵，而是：

> 查理带着“看不见世俗”的悲剧回到研究所，目击阿尔吉侬正在衰退；在迫使研究员说明真相后，他接受手术的代价与自己的选择，决定不让阿尔吉侬独自面对余下的路。

#### 空间环境

第四章全部发生在研究所内部，不回到城市。研究员实际上在第二章的测试现场中一直与查理同处一室或站在终点、高处观察；查理将听到的声音误认为来自广播、通讯设备或墙后。第四章通过研究员的反问重新解释这一事实，但不能把“声音来自喇叭”写成客观设定。

研究员可以继续以声音参与叙事。对查理而言，他仍然无法看见或定位研究员的身体；“研究员就在现场”是双方对话揭示的事实，不意味着画面中必须出现可见的研究员模型。

#### 玩法与演出重点

本阶段只确定章节级的大纲和大致剧情走向，不预写具体对白、逐节点演出、触发时机、Part 失灵形式或导演实现：

- 复用第二章旧实验空间、旋转机关和候选连接，不新增能力系统；
- 通过四个旧空间的反向回返，表现从异常出现到真相闭合的过程；
- 阿尔吉侬的衰退、查理看不到世俗、研究员的解释和查理的接受，分别放入不同关卡承担；
- 任何后续玩法表现都必须服务于关卡叙事，不能破坏解谜公平性；
- 查理不能被写成突然失去人格或尊严，第四章也不能用持续争吵代替剧情推进。

#### 关卡安排

第四章的四关只确定以下大致剧情走向，具体对白、演出节点、触发时机和导演实现另行设计：

##### 4-1：空实验室——悬念

复用 2-4 的出口与 Lift 空间。查理回到研究所后，在自己的观测中发现实验室空无一人；探索时听见隔壁传来研究员断断续续的异常测试声音，于是决定前往隔壁。只有悬念，不解释手术、不解释衰退、不发生交锋。

**剧情目的：** 完成从城市回到研究所的转场，建立异常，并把查理引向 4-2。

##### 4-2：迟疑的轨迹——目击

复用 2-3 的滚筒寻路测试空间。查理看到阿尔吉侬已经不再保持第二章的异常敏捷，而是出现迟疑和停滞。研究员暂时将其解释为疲劳，查理仍认为自己可以帮助它解决问题。

**剧情目的：** 让玩家确认“研究所回来了，但阿尔吉侬已经不一样了”，建立阿尔吉侬正在衰退、查理仍觉得自己能对抗的状态。

##### 4-3：看不见的人——交锋

复用 2-2 的空间联系训练空间。查理向研究员追问阿尔吉侬的异常，并明确说出自己在城市中无法观测世俗生活。研究员由此意识到，查理一直无法观测实际在场的自己。双方在本关完成全章唯一一次集中交锋，并决定回到最初的手术记录。

**剧情目的：** 揭示查理看不见世俗，重新解释第二章，并把两条悲剧汇聚到同一个问题上。交锋不延续到 4-4。

##### 4-4：手术记录——解释与接受

复用 2-1 的手术与最初测试空间。研究员明确解释手术如何让查理获得隐藏空间连接、又失去对世俗生活的稳定接收；同时说明阿尔吉侬手术前和查理离开时没有明确副作用，是在查理离开后才逐步出现衰退。查理承认自己当初因急于改变而选择手术，接受手术代价，并决定陪伴阿尔吉侬。

**剧情目的：** 闭合“查理看不见世俗”和“阿尔吉侬正在衰退”两条悲剧线，完成研究员的明确说明、查理的责任确认和情绪接受，为第五章建立动机。

#### 第四章的信息边界

本阶段暂不确定：

- 具体对白；
- 对白数量、模式和触发点；
- 逐节点演出；
- Part 失灵的具体形式和发生时机；
- 阿尔吉侬每次停顿的位置和时长；
- 导演状态机和代码实现。

后续设计必须保持以下节奏：

```text
4-1 悬念
  → 4-2 目击
  → 4-3 一次交锋
  → 4-4 明确解释与接受
```

### 章节五：给阿尔吉侬的花

#### 剧情功能

第五章是独立的归还与纪念篇，空间环境不再是城市或实验室，而是通往阿尔吉侬墓地的真实道路与花园。错视路径最终退潮，城市世俗世界的观测缺失延续为背景状态；查理仍保留感情、记忆的残片和完成约定的行动。

第五章不再追问如何恢复能力，也不安排新的实验解释。它只完成一个简单动作：

> 查理沿真实道路去阿尔吉侬那里，放下一束花。

#### 空间环境

第五章全部发生在通往阿尔吉侬墓地的真实道路与花园，不返回实验室。

#### 玩法重点

- 只使用稳定、真实的局部固定边；
- 不加入新机关，不把结尾做成最终谜题；
- 查理仍然可以正常移动，不能用失控或迟钝表达衰退；
- 对世俗世界的观测缺失不需要再解释，空旷空间已经成为常态；
- 结尾的完成感来自抵达和纪念，而不是解开空间难题。

#### 关卡安排

第五章共 3 关。结尾不显示“完成实验”“恢复智力”或“拯救查理”。

```text
查理放下花。
建筑没有改变。
人也没有回来。
但这条路是真实存在的。
```

## 七、人物与环境的压缩方案

### 1. 查理

- 查理是唯一的主操作角色。不需要复杂技能树、智力数值或“观测值”。

他的变化通过以下内容表现：

- 关卡中可理解的空间关系逐渐增多，又在后期逐步失效；
- 城市中的世俗事物从查理的空间观测中逐渐缺席，但这不是普通人的实际消失；
- 阿尔吉侬在第一、二章建立关系，并在第四、五章承担衰退与纪念线索；第三章不出现；
- 章节空间从陌生实验室，转为有人生活却无法被查理观测到世俗活动的城市，再沿第二章相反方向回到研究所内部，最后进入真实道路与花园；
- 关卡从局部固定边扩展到更多视觉候选边，再逐渐回到真实固定边；
- 查理从依靠熟悉的生活记忆行动，变为主动观察空间关系，再在第四章得知手术代价并决定陪伴阿尔吉侬；
- 文案从具体、断续的自我记录，逐渐变得完整、精确，再出现遗忘和简化；
- 旧连接后来逐步失效，但这不等于查理的人格或尊严失效。

### 2. 阿尔吉侬

阿尔吉侬在第一、二章作为先行者和空间对照对象建立关系。第三章的城市探索不出现阿尔吉侬；它不承担查理确认空城的证据，也不成为查理回研究所的动机。第四章开始，阿尔吉侬的衰退才进入主线；第五章则成为纪念与情感收束的核心。

阿尔吉侬不建议一开始就做成双角色同步控制系统。

它可以采用三种表现：

1. 在第一、二章中提前走过一条路径；
2. 在第一、二章中作为移动白点或小型角色出现；
3. 在第四章以后停在曾经可以通过的位置，表现衰退与关系变化。

它的玩法职责是：

> 在第一、二章帮助玩家理解查理的空间处境，在第四、五章承载衰退与纪念；不介入第三章的空城探索。

它可以像 Totem 一样先作为功能性参照物，之后通过重复出现自然产生情感连接。

### 3. 爱丽丝

爱丽丝是叙事锚点，不做陪玩角色。

她可以通过：

- 章节之间的一句短记录；
- 一张研究笔记；
- 远处的剪影；
- 一次短暂的等待动作；

来保持存在。她的作用是让玩家知道，仍有人把查理当作一个人，而不只是实验结果。

### 4. 科学家、同事和家庭

不需要全部变成角色。可以把他们合并为三类环境：

| 建筑空间 | 叙事作用 |
|---|---|
| 面包店 / 低处街区 | 查理原本的生活 |
| 研究所 / 高塔 | 实验、学术和被观察 |
| 花园 / 墓地 | 阿尔吉侬、记忆和最终归还 |

这样既保留原著的社会和情绪轮廓，又避免角色数量膨胀。

## 八、哪些原著内容删掉，哪些必须保留

### 可以删掉或合并

第一版不需要完整表现：

- 面包店同事群像；
- 费伊的恋爱支线；
- 母亲与妹妹的大量童年回忆；
- 学术会议具体争论；
- 科学家之间的竞争；
- 收容机构的完整社会细节；
- 复杂医学解释；
- 原著进度报告中的全部事件。

这些内容在小说中有价值，但不一定适合固定相机的空间错视游戏。

### 必须保留

至少保留：

1. 查理想理解别人能够理解的不可能路径；
2. 阿尔吉侬是第一、二章中的先行者和空间对照对象；
3. 查理经历一段短暂的清晰期，空间关系向他打开；
4. 城市中的世俗世界从查理的空间观测中缺席，他因此回研究所询问原因；
5. 第四章固定为四关：4-1 悬念、4-2 目击阿尔吉侬衰退、4-3 查理与研究员的一次集中交锋、4-4 研究员明确解释手术和衰退时间线并由查理接受；
6. 查理最后沿真实道路走到阿尔吉侬那里，放下一束花。

```text
可能被拒绝的错误连接：

关键操作：
操作后产生的视觉变化：

角色如何证明路径成立：

关卡结束时的建筑状态：
关卡结束时的角色状态：
玩家带走的新规则：
下一关继承的新问题：

文本或声音是否必要：
如果删除文本，玩家是否仍能理解主要变化：
```

每关必须能写出一句玩法句子：

```text
玩家通过改变 X，使 Y 成为可达状态，
从而理解 Z。
```

如果一关无法写出清晰的玩法句子，通常说明机制、叙事目的或空间目标还没有收敛。

## 十、关卡与叙事的检查标准

### 玩法可读性

- 初始目标是否清楚可见？
- 玩家是否知道应该观察哪个机关？
- 机关操作是否能产生可观察结果？
- Snap 状态是否离散、稳定、可理解？
- 视觉连接是否有足够证据？
- 角色是否能证明路径真正成立？
- 失败后玩家是否知道哪个连接假设不成立？
- 重置是否足够快？

### 叙事服务玩法

- 本关是否有明确的进入动机？
- 叙事是否没有替代玩家观察？
- 重要变化是否绑定了建筑、角色或路径状态？
- 删除文本后，玩家是否仍能完成当前玩法？
- 过场是否产生新的可操作状态？
- 是否避免把每个机关强行解释成一个象征？

### 多关卡节奏

- 本章引入了什么新规则？
- 本章是否有复习和变奏，而不是连续堆新机制？
- 本章是否有一个视觉高潮？
- 本章是否有至少一个缓冲或留白段落？
- 下一章继承的是问题和理解，而不是单纯数值难度？
- 关卡是否保持自包含，又对整体阶段有贡献？

### 角色关系

- 阿尔吉侬是否有明确的操作或观察功能？
- 角色关系是否改变了玩家的行动或空间理解？
- 对话是否避免复述玩家刚看到的机关？
- 情绪峰值是否与玩法峰值合理重合、错开或递进？
- 是否保留足够留白，让玩家自行解释？

### 伦理与人物表达

- 是否避免把能力差异做成羞辱或惩罚？
- 是否避免把查理的衰退表现为玩家被强制降低操作能力？
- 是否保持“看见路径不是尊严来源”的底线？
- 阿尔吉侬是否是一个被记住的生命，而不只是剧情开关？
- 结尾是否避免把悲剧包装成奖励或胜利？

## 十一、当前项目的推荐实施顺序

本文不要求立即实现完整五章。建议按以下顺序推进设计验证：

### 阶段一：白盒验证核心节奏

先用现有最小关卡验证：

```text
看不见不可能的路径
  -> 角色沿真实道路前进
  -> 看到另一种通过方式
  -> 建筑关系改变
  -> 不可能路径成为可达路径
```

这一组关卡在剧情上对应第二章“盲点重塑”到“独行的轨迹”，而不是第一章。第一章只验证陌生环境、局部记忆空白和“门可能带来答案”的动机。

### 阶段二：扩展同一机制的三个变奏

围绕现有旋转和视觉连接，验证：

1. 单一候选连接；
2. 多个 Snap 状态中的正确状态；
3. 跨 Part、远处 Part 和遮挡拒绝。

这三类关卡主要承担第二章前半和后续章节的白盒，不再把它们默认归入第一章。

### 阶段三：加入阿尔吉侬的轻量表现

优先只做：

- 第一、二章中让阿尔吉侬远处提前走过一条路；
- 第一、二章中让它与查理的路径形成对照；
- 第四章以后让它停在曾经可走的位置，表现衰退。

第三章不加入阿尔吉侬表现，不先做完整双角色同步控制。

### 阶段四：验证“旧连接失效”但不降低玩家能力

使用已有视觉候选评估和遮挡拒绝，设计旧路径不再成立的关卡。重点验证：

- 失效是否可观察；
- 玩家能否理解是空间连接改变，而不是操作失灵；
- 是否仍有稳定的局部固定边通往目标；
- 关卡重置和反馈是否足够温和。

### 阶段五：最后设计花园收束

花园不是最终复杂谜题，而是一个低复杂度的真实道路关卡。它的任务是收束情绪，不是证明玩家掌握了更多系统。

## 十二、授权与原创化边界

如果项目正式商业发布，直接使用以下内容通常需要确认改编授权：

- 查理·戈登；
- 阿尔吉侬；
- 爱丽丝·金尼安；
- 原著特定事件；
- 原著文本或改写文本；
- 原著中具有明确识别度的专有表达。

如果暂时没有授权，可以采用主题原创化：

- 将查理改为原创角色；
- 将阿尔吉侬改为另一种实验生物或陪伴对象；
- 保留“短暂获得看见世界的能力，最终回到真实道路并留下纪念”的主题结构；
- 不使用原著专有名字、段落和句子。

两种方向在关卡骨架上仍可以共用：

```text
愿望
  -> 实验
  -> 看见
  -> 高峰
  -> 对照者先衰退
  -> 连接失效
  -> 真实道路
  -> 纪念
```

本节是设计和风险提示，不构成法律意见。

## 十四、最终设计原则

将本次调研压缩成项目可执行的原则：

1. 先确定玩家在本关要感受到什么，再确定需要解释什么；
2. 每一关只承担一个主要叙事动作；
3. 让主题进入路径、机关、角色位置或环境状态，而不是只进入对白；
4. 让玩家先做出行为，再理解行为的意义；
5. Path Graph 是玩法计算结果，不是叙事文本对象；
6. 文本只补充空间无法可靠表达的事实；
7. 机制先展示，再变奏，最后组合；
8. 失败应暴露错误的连接假设，而不是惩罚玩家；
9. 角色关系应有操作意义，但不应成为第二套竞争玩法；
10. 每个关卡需要一个清晰的视觉句号；
11. 章节以体验和认知切换组织，而不是只按地图分区；
12. 关卡节奏以惊喜密度为主，不以持续增加难度为主；
13. 旧机制的重新解释比每章增加全新系统更重要；
14. 查理的衰退应表现为世界连接逐渐失效，而不是玩家操作能力被降低；
15. 阿尔吉侬是对照物和被记住的生命，不只是剧情开关；
16. 结尾的花不是通关奖励，而是对一段关系的纪念；
17. 玩法、角色和空间状态必须形成完整链路：

```text
玩家做了什么？
  -> 玩家因此理解了什么？
  -> 这个理解为什么让角色或世界变得不同？
```

如果这三个问题能在一个关卡中闭合，玩法与叙事就不再是两条并行轨道，而是同一个设计系统。
