# 《献给阿尔吉侬的花束》主题融入方案：多关卡错视解谜的轻叙事设计

## 文档定位

本文记录本项目围绕《献给阿尔吉侬的花束》进行的剧情与关卡线调研结论，以及基于当前“六边形纪念碑谷”玩法架构形成的设计方案。

本方案的核心前提是：

> 不是让故事驱动玩法，也不是把小说拆成一关；而是让多关卡玩法推动玩家逐步理解故事，让轻叙事为玩法提供方向、情绪和记忆点。

本文只描述剧情、关卡线和叙事—玩法关系，不规定具体脚本实现，也不替代当前 Path Graph、机关 Snap、固定相机和关卡数据架构文档。

---

## 一、设计结论摘要

### 1. 产品形态

项目应当是一个由多个独立视觉谜题组成的错视解谜游戏：

```text
章节
  -> 多个自包含关卡
    -> 观察固定相机下的空间
    -> 操作建筑机关
    -> 形成合法视觉连接
    -> 角色自动通过路径
    -> 关卡状态和叙事状态产生余波
```

它不是：

- 一关完成的文学寓言；
- 以文本为主体的视觉小说；
- 关卡之间插入长篇剧情的传统剧情游戏；
- 把智力、记忆或能力做成数值升级的游戏；
- 用每一个机关强行对应一个文学隐喻的符号解谜。

### 2. 叙事尺度

《献给阿尔吉侬的花束》需要缩略，但缩略的对象是剧情事件数量，不是玩家体验长度。

原著的复杂人生被压缩为：

```text
愿望
  -> 实验
  -> 高峰
  -> 预兆
  -> 衰退
  -> 送花
```

这条主线再展开成多个关卡，让玩家经历：

```text
无法到达
  -> 第一次形成错视连接
  -> 看见更多连接
  -> 连接变得复杂
  -> 连接开始失效
  -> 回到真实道路
  -> 给阿尔吉侬放花
```

因此最终作品不是“简化版小说”，而是：

> 一个借用《献给阿尔吉侬的花束》情绪脊骨的多关卡错视解谜游戏。

### 3. 叙事与玩法的耦合度

建议采用三层耦合，而不是强绑定。

#### 第一层：每关有叙事动机，但不解释谜题

玩家只需要知道：

- 为什么来到这里；
- 想去哪里；
- 完成后发生了什么变化。

谜题规则由玩家观察建筑、机关和角色行动自行理解。文本不解释“这座旋转塔代表查理的大脑”，也不解释“这两条投影边为什么能连接”。

#### 第二层：章节变化由玩法结果推动

玩家完成一组空间问题后，世界状态发生变化：

- 研究所打开；
- 新的建筑区域出现；
- 远处的道路变得可达；
- 阿尔吉侬的旧路径开始失效；
- 研究所重新变得封闭；
- 查理最终回到真实道路。

剧情变化来自关卡完成后的状态，而不是来自独立于玩法之外的剧情系统。

#### 第三层：少数关键转折真正改变玩法

适合进入玩法的转折只有少数几个：

1. 无法通过普通道路；
2. 获得一种新的“看见连接”的方式；
3. 阿尔吉侬先出现衰退，成为未来预兆；
4. 借来的道路逐渐失效，最后回到真实道路。

面包店同事、母亲、妹妹、学术会议、恋爱关系等内容可以合并为环境、短文本或剪影，不必逐一变成新的关卡系统。

## 二、当前项目玩法基础

本方案建立在现有项目文档定义的玩法目标上。

### 1. 项目目标

项目是“六边形纪念碑谷”式错视解谜游戏。三棱柱体素、Part、Object Tree 和局部体素编辑器服务于关卡制作、白盒搭建和运行时 Debug，不是最终产品方向。

核心玩法闭环是：

```text
固定正交视角观察建筑
  -> 玩家操作六向建筑机关
  -> 建筑状态改变视觉对齐关系
  -> 固定相机下出现新的视觉连接
  -> 当前有效 Path Graph 生成新边
  -> BFS 寻路
  -> 小人自动走到目标
```

当前最小验证场景是：

```text
起点平台 -> 中央六向旋转结构 -> 目标平台
```

旋转前不可达，旋转后通过错视连接可达。

### 2. 玩家核心循环

```text
观察固定视角下的建筑
  -> 看见一个可见但不可达的目标
  -> 观察机关与道路端点
  -> 拖动建筑机关
  -> Snap 到合法离散状态
  -> 固定相机下视觉连接成立
  -> 当前有效 Path Graph 刷新
  -> 点击目标
  -> 小人自动沿路径抵达
```

游戏过程不是自由控制角色，而是让玩家通过建筑操作改变角色可走的路径。

### 3. Path Graph 的职责

当前有效 Graph 由以下信息派生：

```text
局部 PathNode
  + Level 候选连接
  + Part 当前 Transform
  + 合法 Snap 状态
  + 固定游戏相机
  -> PathRuntime
  -> CurrentEffectiveGraph
  -> BFS / Character
```

寻路只消费当前有效 Graph。角色、Mesh、Scene Node 和物理碰撞不能反向定义关卡连接。

### 4. 视觉连接的基本语义

跨 Part 的错视连接满足：

```text
两个候选可走面
  -> 应用各自 Part Transform
  -> 使用固定游戏相机投影
  -> 对应面边共线且正长度重合
  -> 重合接缝没有更近逻辑体素面遮挡
  -> 形成 accepted visual edge
```

因此：

- 真实空间不必相接；
- 面不必共面；
- 法线不必相同；
- 只有端点接触不算连接；
- 深度差不能替代投影边重合；
- 遮挡证据不足时不能自动通过；
- 更近的逻辑体素面切断接缝时应拒绝连接。

### 5. 机关状态边界

机关采用离散 Snap 状态：

```text
rotatorStep = 0..5
```

动画中只更新表现层 Transform，不更新玩法 Graph。Snap 完成后才提交离散状态、重新评估视觉候选并原子替换当前有效 Graph。

这条边界对叙事也很重要：

> 只有玩家真正完成一次建筑理解，世界才确认新的道路；半旋转不是故事状态，也不是玩法状态。

## 三、纪念碑谷三部曲的叙事与关卡调研

本节总结对《Monument Valley》1、2、3 的外部调研。以下内容区分“较高可信度事实”和“设计归纳”。

### 1. 共同结构

三部作品并不是先写出完整剧情，再用关卡承载剧情；更接近于：

> 先建立一个可感知、可操作的空间体验，再让角色目标、机关变化和环境变化承担叙事功能。

三部作品共同采用：

1. 文本极少，故事主要由空间、角色动作、色彩、音乐和机关变化表达；
2. 每个关卡既是一个谜题，也是一个独立的视觉与情绪段落；
3. 章节不是传统剧情任务链，而是由“新机制—变体—高潮展示—情绪留白”组成的体验序列；
4. 角色与机关的关系会随叙事主题变化；
5. 玩法表达的不是具体剧情细节，而是关系状态、情绪转折和主题隐喻；
6. 可理解、可完成、低挫败优先于持续堆叠高难度；
7. 关卡结尾通常提供视觉句号，而不是完整解释世界观。

### 2. 第一部：空间、宽恕与归还

《Monument Valley 1》的官方产品描述包含“A Quest for Forgiveness”，即“寻求宽恕的旅程”。玩家引导沉默的公主穿越神秘纪念碑，操纵建筑、创造路径并揭示隐藏空间。

较高可信度的设计事实包括：

- 游戏受到 M.C. Escher 不可能几何的启发；
- 团队不希望只制作传统意义上“有挑战的谜题”；
- 目标偏向审美和情绪体验；
- 每个画面应当像一件独立的艺术品；
- “短而 sublime”是有意的体验策略。

其叙事主要由以下元素承担：

| 关卡元素 | 叙事作用 |
|---|---|
| 神圣、空旷、带有仪式感的建筑 | 建立古老文明、失落秩序和神秘感 |
| 角色在不同纪念碑之间持续前进 | 形成旅程结构 |
| 隐藏路径被揭开 | 将发现真相转化为操作行为 |
| 破碎、封闭或循环空间 | 暗示失序、阻隔与过去的负担 |
| 机关重新连接、建筑恢复运作 | 让修复和归还成为可见结果 |
| 结尾仪式空间和色彩变化 | 提供情绪收束，而不是解释所有历史 |

重要判断：

- 事实是游戏的主题包含宽恕，关卡围绕穿越纪念碑、寻找路径和完成仪式性目标组织；
- “玩家通过把不可行走空间变成可行走空间，体验从混乱走向秩序”是合理的设计推断，而不是每个机关都对应某个具体剧情事件。

### 3. 第二部：母女关系直接变成操作关系

《Monument Valley 2》围绕母亲 Ro 和她的女儿展开。它是三部作品中叙事与机制结合最明确的一部。

可确认的结构包括：

- 玩家同时接触母亲和女儿；
- 早期母女可以作为一个整体移动；
- 后续通过破碎通道等空间变化将两人分开；
- 女儿拥有跟随、独立行动和参与机关的阶段变化；
- 某些谜题要求两个角色分别站到机关位置或互相打开通路；
- 游戏主要使用色彩、关卡设计、机制变化和角色动作，而不是传统对白表达关系。

其关系结构可以分成四阶段：

#### 阶段一：共同移动

母亲和女儿作为一个行动单位。玩法表达依赖和引导，玩家实际负责带着孩子前进。

#### 阶段二：空间分离

道路断裂或区域分开，玩家不能再把母女当作一个整体。空间距离直接被体验为关系变化。

#### 阶段三：互相协作

两个角色分别操纵不同机关，女儿从被带领的对象变成谜题链条中的主动节点。亲子关系从单向照顾转为互相支持。

#### 阶段四：独立行动与重新连接

女儿获得独立解决问题的能力，关系从依赖转为支持。目标不是永远绑定，而是在不同路径成长后再次连接。

### 4. 第三部：光、灯塔、自然与环境危机

《Monument Valley 3》的主角是灯塔学徒 Noor。其世界包含光明消退、灯塔、水域、船、上涨的水域以及建筑与自然的冲突。

开发者资料强调了一个重要变化：

> 在前两部中，建筑是主要角色之一；第三部希望让自然也成为重要的叙事和设计对象。

可借鉴的结构包括：

| 机制或环境 | 叙事功能 |
|---|---|
| 灯塔 | 世界秩序、社区安全和持续性的中心 |
| 光 | 资源、希望和恢复目标 |
| 船 | 从封闭纪念碑走向更大环境 |
| 上涨水域 | 让环境危机具备空间和视觉即时性 |
| 植物与建筑融合 | 让自然成为关卡参与者 |
| 城市与自然碰撞 | 让空间承载环境主题 |

媒体将其解读为环境主义、气候迁移或“希望朋克”，但这些属于评论性阐释，不能全部当作开发者明确的剧情定义。

### 5. 纪念碑谷的关卡组织

更可靠的组织方式不是固定关卡数量，而是关卡体验节奏：

```text
引入
  -> 机制变体
  -> 关系或主题变化
  -> 视觉高潮
  -> 缓冲或留白
```

关卡往往是独立的视觉短篇：

1. 用一个清晰画面提出问题；
2. 让玩家学习空间规则；
3. 通过变体打破预期；
4. 在结尾用视觉变化完成高潮；
5. 让角色动作或环境状态提供收束。

其节奏重点是“惊喜密度”而非单纯难度：

- 更换空间形态；
- 引入新的视觉规则；
- 让同一机关产生不同含义；
- 增加角色之间的空间依赖；
- 将局部空间扩展成多个层次；
- 让玩家在熟悉规则后看到更大的视觉结果。

### 6. 纪念碑谷调研的直接借鉴

对本项目最重要的不是复制具体机关，而是复制职责分工：

- Path Graph 是当前有效连接的计算结果，不是玩家要阅读的叙事对象；
- 每个章节围绕一种空间命题；
- 机关状态可以承担情节转折；
- 角色应成为路径变化的见证者；
- 关卡结束时让建筑、角色或环境状态发生可见变化；
- 轻叙事不等于没有主题，而是不把主题全部写成说明。

## 四、独立游戏“叙事服务于玩法”的调研

### 1. 三种关系

#### 类型一：叙事为玩法提供动机

叙事回答：

- 为什么我要去那里？
- 为什么我要观察这个物件？
- 为什么这个空间值得重新理解？
- 为什么我愿意继续尝试？

《Outer Wilds》是典型案例：玩家不是依赖传统任务列表和装备升级，而是因为新的问题、新的线索和新的世界规律继续探索。

#### 类型二：玩法表达叙事主题

主题不只写在对白里，而是出现在玩家反复执行的行动中。

相关案例包括：

- 《Celeste》用反复尝试、失败、坚持和对抗内在自我表达心理挣扎；
- 《Gorogoa》用拼接、重叠和重新理解视觉关系表达记忆、时间与破碎经验；
- 《What Remains of Edith Finch》让不同家庭成员拥有不同的操作方式，使生活方式和死亡方式直接成为可玩体验；
- 《Monument Valley》让空间规则承担情绪和关系表达。

#### 类型三：玩法产生叙事解释

玩家先遇到系统现象，再逐渐建立世界观解释。

相关案例包括：

- 《The Witness》先让玩家理解图形规则，再让玩家意识到岛屿、建筑、声音和符号之间存在更大的关系；
- 《Outer Wilds》先经历时间循环和空间变化，再拼出宇宙历史；
- 《Return of the Obra Dinn》先观察人物、空间和死亡场景，再通过调查构建事件真相。

本项目最适合结合类型一和类型二，并适度使用类型三：

```text
故事给玩家一个想去哪里的理由
  -> 玩家通过操作建筑产生实际理解
  -> 玩家从空间结果推断查理经历的变化
```

### 2. 信息粒度

叙事信息应匹配玩家当前行动，不要一次解释完整故事。

#### 层级 A：即时操作信息

回答：

- 这个机关能不能操作？
- 这段路能不能走？
- 这两个区域是否存在连接？

优先用视觉、声音、动画和空间布局表达。

#### 层级 B：局部因果信息

回答：

- 为什么这条路断开？
- 为什么机关改变后道路成立？
- 为什么两个空间可以连接？

最好通过玩家操作后的结果表达。

#### 层级 C：区域或章节信息

回答：

- 这里发生过什么？
- 这个空间属于谁？
- 这一章的情绪是什么？

可以用少量文本、环境陈设、角色反应和视觉主题表达。

#### 层级 D：世界背景信息

包括历史、家族、实验背景和社会环境。这类信息不应阻塞当前玩法，可作为可选阅读、隐藏线索或后续重解释。

### 3. 关卡作为叙事单元

每个关卡可以被视为一个完整叙事段落：

```text
建立当前状态
  -> 玩家看见异常
  -> 玩家形成局部假设
  -> 玩家操作空间或机关
  -> 视觉连接或逻辑关系成立
  -> 玩家获得路径、信息或情绪结果
  -> 下一关继承新的问题
```

适合空间错视游戏的“叙事动作”包括：

- 对齐两个原本分离的结构；
- 将角色送到一个不可能到达的地方；
- 旋转空间后发现旧路径；
- 让一个机关从障碍变成桥梁；
- 将物件放回原位；
- 复原一个被破坏的结构；
- 通过不同空间的相似布局推断历史联系。

### 4. 机制引入、变奏与组合

机制引入建议遵循：

```text
展示规则
  -> 安全尝试
  -> 一次直接使用
  -> 改变一个变量
  -> 要求玩家迁移理解
```

机制变奏应保持一个核心不变量，只改变对象、时机、空间关系或叙事语境。

组合应遵循：

```text
机制 A 单独教学
  -> 机制 B 单独教学
  -> A/B 并列但互不干扰
  -> A/B 产生相互影响
  -> A/B 在叙事上产生新含义
```

推荐给每关写一句“玩法句子”：

```text
玩家通过改变 X，使 Y 成为可达状态，
从而理解 Z。
```

例如：

```text
玩家通过旋转中段塔体，
使两条不连续的楼梯在固定视角下重合，
从而理解这个世界的道路不是由物理连续性决定，而是由视觉连接决定。
```

### 5. 失败和重试

本项目不需要传统死亡。空间解谜可以使用软失败：

- 角色走入死路；
- 机关进入不可用状态；
- 视觉连接短暂成立但无法通行；
- 玩家发现一种假设不成立；
- 空间状态需要重置。

失败至少应有一种价值：

1. 提供规则信息；
2. 缩小解空间；
3. 建立情绪意义。

对本项目而言，失败应暴露错误的连接假设，例如：

- 玩家以为两段路在所有状态都相连，但角色走到边缘后停住；
- 玩家以为机关只影响眼前部分，但远处道路也发生变化；
- 玩家以为视觉重合就是逻辑可达，但接缝被遮挡；
- 玩家以为某个 Snap 合法，但证据不足，连接不被 Graph 接受。

重试应快速，不重复已经没有价值的动画和长路径。

### 6. 角色关系如何不抢玩法

最有效的角色关系不是让角色长时间谈论关系，而是让玩家操作关系本身。

可用的关系机制包括：

- 一个角色改变另一个角色的可达路径；
- 两个角色必须保持某种空间关系；
- 玩家决定谁先通过、谁留下；
- 角色移动方式表达性格；
- 角色对空间变化产生不同反应。

但角色关系不能成为第二套竞争玩法。应遵守：

- 对话不解释玩家已经看见的内容；
- 关系变化必须改变下一次行动，或至少改变玩家对空间的理解；
- 角色信息分散在移动过程中，保留留白；
- 先让玩家“做过”，再让角色“说出一点”。

### 7. 文本、语音与过场边界

建议表达优先级：

```text
空间关系
  > 角色行动
  > 机关反馈
  > 环境声音
  > 短文本或语音
  > 完整过场
```

文本适合表达：

- 精确名称、地点和人物关系；
- 无法从环境可靠看出的历史信息；
- 章节之间的连接；
- 已经体验过但还没有完全理解的情绪背景；
- 可选的深层背景。

文本不适合：

- 复述玩家刚刚看到的机关结果；
- 解释每个机关的象征意义；
- 替代角色动作；
- 频繁打断操作。

过场适合表现时间跨度、无法直接交互的历史事件、章节状态切换和关系结束，但过场之后必须产生可操作回声：

- 新的空间状态；
- 新的可走面；
- 新的机制约束；
- 新的角色关系；
- 新的玩家问题；
- 对旧空间的重新解释。

## 五、原创游戏的总体剧情线

### 1. 故事核心

建议保留以下五个核心事实：

1. 查理想要变聪明；
2. 阿尔吉侬是先行者，也是对照；
3. 查理获得了一段短暂的高峰；
4. 阿尔吉侬先衰退，查理因此知道自己的结局；
5. 查理最后给阿尔吉侬送花。

这些内容已经足够构成完整游戏叙事。

### 2. 故事脊骨

```text
查理想要走通一条别人走过的路
  -> 他进入实验，开始看见建筑之间隐藏的连接
  -> 他掌握越来越复杂的空间关系，走到世界高处
  -> 阿尔吉侬先走不通曾经熟悉的迷宫
  -> 查理发现自己借来的道路也正在消失
  -> 他回到稳定、真实的道路
  -> 他走到阿尔吉侬的墓前，放下一束花
```

### 3. 不应做的叙事误读

不要把：

```text
旋转机关 = 聪明
视觉连接 = 智商
连接失效 = 查理受到惩罚
Path Graph = 查理的心理状态
```

作为一一对应的硬编码隐喻。

更合适的关系是：

> 玩家在不断重新理解空间；查理也在不断重新理解自己所处的世界。空间经验与人物经历产生共振，但不强行规定唯一解释。

### 4. 关于“变聪明”的表达

不建议：

- IQ 数值；
- 技能树；
- 直接解锁“聪明等级”；
- 用操作速度或移动能力体现智力；
- 后期故意让玩家操作变慢或变笨。

推荐通过以下方式表达：

- 关卡中可理解的空间关系逐渐增多；
- 研究所环境从低矮、封闭变成高耸、开放；
- 关卡从局部固定边扩展到更多视觉候选边；
- 文本从简单报告变得完整，再逐渐简化；
- 查理从迟疑、等待变为主动观察和行动；
- 旧连接后来逐步失效。

这里的“变聪明”首先是玩家对空间语言的学习，同时与查理的经历形成共振，而不是给角色装备一项永久能力。

## 六、多章节、多关卡设计方案

建议设计为五章、18 关，按 3-4-4-4-3 排布。如果第一版需要收敛，可以压缩为四章、12 关。章节数不是必须一次性实现的内容，而是完整剧情线的规划骨架。

### 章节一：跑不过的迷宫

#### 剧情功能

第一章不急着让玩家掌握全部错视玩法，而是先建立查理、阿尔吉侬和实验之间的关系：

- 查理想走到门那里；
- 阿尔吉侬已经能够走到更亮的地方；
- 查理可以沿真实道路前进，却无法跨越某种天然的空间断裂；
- 研究人员让查理先看见一种新的可能，再由查理决定是否进入实验。

第一章的核心不是“查理解不开迷宫”，而是：

> 玩家亲眼看到，有一条路确实存在，但它不属于现在的查理。

#### 玩法重点

- 第一关只使用局部固定路径；
- 第二关使用一次预设的阿尔吉侬飞跃，建立角色差异；
- 第三关使用一次由研究人员触发的 Part 被动旋转，展示视觉连接。
- 第一章共 3 关：1-1 门、1-2 白鼠先行、1-3 另一种世界。玩家自己转建筑从第二章开始，不是第一章的第四关。

#### 关卡安排

| 关卡 | 玩法与表现 | 叙事作用 |
|---|---|---|
| 1-1 门 | 黑色脑形迷宫中，查理沿着实打实的道路走向唯一的门 | 建立查理“想走出去”的愿望 |
| 1-2 白鼠先行 | 两扇门分别发出明亮和暗淡的光。阿尔吉侬先穿过迷宫，在沟壑处突然飞起，越过沟壑后进入明亮的门；玩家操控查理时，无论怎样寻路都只能沿真实路径走到暗淡的门 | 玩家亲眼看到阿尔吉侬走过一条查理走不过的路线，建立比较与实验对象关系 |
| 1-3 另一种世界 | 布局与 1-2 相似但略有变化，仍有一处沟壑。阿尔吉侬再次飞过沟壑；查理以为自己仍然只能走向暗淡的门。此时研究人员让沟壑所在的 Part 被动旋转，沟壑两侧在固定视角下连接，查理第一次看到原本断开的路变成可走路径 | 研究人员向手术前的查理展示“如果手术成功，世界可能这样打开” |

#### 1-1：门

- 黑色背景表示查理此刻封闭、孤独、缺少方向的主观处境；
- 脑形迷宫可以形成主题联想，但不在文本中直接解释为“查理的大脑”；
- 唯一发光的门是明确目标，也是查理愿望的外化；
- 玩家只需学会点击目标、沿真实路径自动行走；
- 这一关不加入旋转、错视连接或失败惩罚。

建议的短文本：

> 我想走到那扇门那里。

#### 1-2：白鼠先行

这一关必须让玩家“眼睁睁地看见”阿尔吉侬走过查理走不过的路线，而不是只通过文字得知两者能力不同。

推荐流程：

```text
查理从起点开始
  -> 阿尔吉侬先行动
  -> 沿一条清晰的真实道路前进
  -> 到达沟壑边缘
  -> 短暂停留
  -> 突然飞过沟壑
  -> 落到另一侧道路
  -> 进入明亮的门
  -> 明亮的门关闭或退入黑暗
  -> 玩家尝试让查理前往同一扇门
  -> 查理在沟壑前停下
  -> 玩家只能沿真实路径抵达暗淡的门
```

这里的“飞过沟壑”是阿尔吉侬的预设表现，不是本章正式引入的角色跳跃规则。它的功能是建立不可逆的事实：

```text
阿尔吉侬能通过某种方式越过这里
查理当前不能
```

两扇门的意义应当明确区分：

- **明亮的门**：阿尔吉侬进入的实验、未知和“更高可能性”；
- **暗淡的门**：查理当前能够抵达的现实出口。

为了避免玩家误以为暗门是错误目标，暗门也应当是可完成关卡的正式出口，只是光线、声音和门后的空间明显更克制。玩家不是“选错了门”，而是被引导去体验两种不同的抵达结果。

建议短文本：

> 它已经走过这里了。
>
> 我也想做到。

这一关不加入：

- 旋转机关；
- 玩家跳跃；
- 双角色同步控制；
- 竞速计时；
- 隐藏的替代路线；
- 因为“查理笨”而改变玩家操作能力的系统。

#### 1-3：另一种世界

这一关不是玩家第一次解谜旋转，而是研究人员给查理看的实验演示。它需要让玩家先产生与 1-2 相同的预期，再亲眼看到预期被改变。

推荐流程：

```text
查理进入与 1-2 相似的新测试场
  -> 阿尔吉侬再次沿既有路径前进
  -> 阿尔吉侬再次飞过沟壑
  -> 阿尔吉侬进入明亮的门
  -> 查理面对同样的沟壑
  -> 玩家预期查理仍然只能去暗淡的门
  -> 研究人员触发沟壑所在 Part 被动旋转
  -> 沟壑两侧在固定相机下对齐
  -> 原本断开的道路形成视觉连接
  -> 查理在新的道路上走向明亮的门
```

这一关的关键不是“研究人员替玩家解谜”，而是让玩家体验一次认知转折：

> 上一关的结论是“查理过不去”；这一关的结论变成“道路本身可以改变”。

这次被动旋转应有以下限制：

- 由剧情演出触发；
- 只展示一个清晰的正确状态；
- 动画期间不刷新玩法 Graph；
- Snap 完成后才提交新的有效连接；
- 不让玩家拖动 Part；
- 不同时引入遮挡判断、多候选连接或多个机关。

#### “是否做手术”的表达

1-3 可以成为“查理是否接受手术”的剧情接口，但第一版不建议马上做成真正的分支剧情。更适合用玩家行动表达选择：

```text
研究人员展示新世界
  -> 明亮的门打开
  -> 暗淡的门仍然保留
  -> 玩家点击或让查理走向明亮的门
  -> 进入下一章的实验阶段
```

这样玩家的操作就是查理的选择，但不会产生两套难以维护的关卡线。如果未来确实要做分支，也应先确认两条路线各自对应完整内容，而不是只做一个“是/否”弹窗。

#### 章节结束

查理通过被动形成的视觉连接进入明亮的门。门后不是完整的剧情过场，而是：

- 研究室的光线第一次照亮查理；
- 观察室中的记录灯亮起；
- 阿尔吉侬在更远处等待；
- 一座新的可动结构出现在画面中。

章节结束时，玩家应该获得三个理解：

```text
查理想走出去
阿尔吉侬能走一条查理走不了的路
建筑的关系可以被改变
```

下一章再把“被动展示的道路”交给玩家主动操控，形成玩法和叙事上的明确分界：

```text
1-3：研究人员让查理看见新的世界
第二章：查理开始自己操控这个世界
```

#### 留下的问题

> 如果这不是阿尔吉侬天生会飞，而是某种可以被给予查理的能力，那么查理愿不愿意进入这个实验？

---

### 章节二：打开的世界

#### 剧情功能

查理接受实验，逐渐进入一个以前无法进入的世界。玩家通过关卡体会空间理解能力的扩大，而不是看到一个“智力升级界面”。

#### 玩法重点

在旋转基础上逐步增加：

- 多个合法 Snap 状态；
- 多个 Part；
- 同一机关对远处 Part 的影响；
- 跨 Part 视觉连接；
- 视觉接缝和遮挡关系。

#### 关卡安排

| 关卡 | 玩法 | 叙事作用 |
|---|---|---|
| 2-1 研究室 | 一个旋转机关制造一条视觉连接 | 建立新道路 |
| 2-2 远处的房间 | 旋转当前 Part，同时改变远方 Part 的关系 | 查理开始看见更大的系统 |
| 2-3 两座塔之间 | 多个候选连接，只有一个合法 Snap 能抵达目标 | 查理超过原有边界 |
| 2-4 高处的窗 | 综合前面机制，完成一次更大的空间揭示 | 进入高峰期 |

第二章共 4 关。

#### 章节结束

查理站在高塔上，看见远处原本看不见的建筑群。研究人员不需要长篇表扬，只需要一句短反馈：

> “现在，他能看见了。”

---

### 章节三：高处没有朋友

#### 剧情功能

这是查理的高峰期，也是最孤独的一章。空间变得更容易被理解，但人与人之间没有同步变得更接近。

可通过环境表达：

- 面包店的人被放在远处或下方；
- 研究人员站在观测台上，把查理当成成果；
- 爱丽丝位于另一条可见但不易抵达的路径上；
- 阿尔吉侬是唯一真正经历同一实验的存在。

#### 玩法重点

不是单纯提升难度，而是让玩家理解：

- 看见更多可能连接；
- 但并非所有看见的连接都可靠；
- 视觉成立不等于路径一定成立；
- 需要观察遮挡、边线和真正的可达关系。

这与当前“遮挡拒绝”和“证据不足”的视觉候选评估方向一致。

#### 关卡安排

| 关卡 | 玩法 | 叙事作用 |
|---|---|---|
| 3-1 玻璃之间 | 多条视觉线索同时出现，只有部分边真正成立 | 看见不代表理解 |
| 3-2 旁观席 | 建筑把查理和远处人群分隔在不同高度 | 站得更高，却更孤独 |
| 3-3 阿尔吉侬的记录 | 阿尔吉侬走过一条与查理不同的路径 | 两个实验对象形成对照 |
| 3-4 最后的报告 | 多 Part、复杂遮挡和多个 Snap 状态综合 | 达到玩法与情绪高峰 |

第三章共 4 关。

第三章应安排一两个安静关卡，不要每关都复杂。节奏应是：

```text
学习 -> 变化 -> 惊喜 -> 留白
```

#### 章节结束

阿尔吉侬第一次没有走通它曾经熟悉的迷宫。不要马上让它死亡，先让玩家通过玩法感受到异常：

- 它停在曾经能通过的位置；
- 它重复走错一条路；
- 它不再响应原来的机关；
- 查理必须回头等它。

随后用很短的研究记录确认：

> “阿尔吉侬的结果开始下降。”

---

### 章节四：道路正在消失

#### 剧情功能

查理知道这条路正在消失，却仍然必须继续走。

这一章不应被设计为“玩家能力下降”的惩罚章节，而是改变世界的合法连接，让玩家体验借来的道路逐渐失效。

#### 玩法重点

重新使用前面学过的机制，但改变空间状态：

- 以前成立的视觉连接现在不再成立；
- 某些候选接缝被遮挡；
- 某些 Snap 状态不再能抵达目标；
- 角色只能回到更稳定的局部固定路径；
- 旧关卡的空间语言被重新理解。

玩家仍然可以正常旋转、观察和寻路，只是世界不再像第三章那样愿意打开。

#### 关卡安排

| 关卡 | 玩法 | 叙事作用 |
|---|---|---|
| 4-1 失效的迷宫 | 复用第一章的某类布局，但旧连接不再成立 | 阿尔吉侬先走不通 |
| 4-2 反向的塔 | 旋转机关仍然工作，但可用连接变少 | 查理发现自己的路也在减少 |
| 4-3 回到低处 | 错视连接只短暂出现，最终必须走局部固定边 | 从借来的道路回到真实道路 |
| 4-4 空房间 | 低复杂度关卡，主要让角色穿过安静的研究所 | 情绪缓冲，不再追求视觉炫技 |

第四章共 4 关。

#### 明确避免

不要加入：

- 智力值下降；
- 操作速度变慢；
- 移动能力被削弱；
- 故意让玩家难以控制；
- “查理变笨所以无法操作机关”的系统解释。

这会把人物悲剧转化为玩家受罚，也会误读原著。

---

### 章节五：给阿尔吉侬的花

#### 剧情功能

最后不是拯救查理，也不是打败反派，而是完成一个简单、真实、仍然可以做到的动作：

> 查理去给阿尔吉侬送花。

#### 玩法重点

刻意降低复杂度：

- 以局部固定边为主；
- 不加入新机关；
- 不设计最终 Boss 式谜题；
- 目标从看见不可能的路变成走完一条真实的路。

#### 关卡安排

| 关卡 | 玩法 | 叙事作用 |
|---|---|---|
| 5-1 真正的路 | 只有稳定、普通的可走面 | 查理仍然能够前进 |
| 5-2 花园 | 一条很短的路径，终点是阿尔吉侬的墓 | 完成送花 |
| 5-3 余光 | 无谜题或极低复杂度尾声 | 给玩家留下空间 |

第五章共 3 关。5-3 是收束尾声，不是额外可选章。

结尾不显示“完成实验”“恢复智力”或“拯救查理”。可以只留下：

```text
查理放下花。
建筑没有改变。
但这条路是真实存在的。
```

---

## 七、人物与环境的压缩方案

### 1. 查理

查理是唯一的主操作角色。不需要复杂技能树或智力数值。

变化通过以下内容表现：

- 可理解的空间关系逐渐增多；
- 建筑由低矮、封闭变为高耸、开放，再重新封闭；
- 关卡从局部固定边扩展到更多视觉候选边；
- 文本从简单报告变得完整，再逐渐简化；
- 角色从迟疑、等待变为主动观察和行动，再回到停留和等待。

### 2. 阿尔吉侬

阿尔吉侬不建议一开始就做成双角色同步控制系统。

它可以采用三种表现：

1. 在少数关卡中提前走过一条路径；
2. 在远处作为移动白点或小型角色出现；
3. 在后半段停在曾经可以通过的位置。

它的玩法职责是：

> 让玩家提前看见查理未来会经历的变化。

它可以像 Totem 一样先作为功能性参照物，之后通过重复出现自然产生情感连接。

### 3. 爱丽丝

爱丽丝是叙事锚点，不做陪玩角色。

她可以通过：

- 章节之间的一句短记录；
- 一张研究笔记；
- 远处的剪影；
- 一次短暂的等待动作；

来保持存在。她的作用是让玩家知道，仍有人把查理当作一个人，而不只是实验结果。

### 4. 科学家、同事和家庭

不需要全部变成角色。可以把他们合并为三类环境：

| 建筑空间 | 叙事作用 |
|---|---|
| 面包店 / 低处街区 | 查理原本的生活 |
| 研究所 / 高塔 | 实验、学术和被观察 |
| 花园 / 墓地 | 阿尔吉侬、记忆和最终归还 |

这样既保留原著的社会和情绪轮廓，又避免角色数量膨胀。

## 八、哪些原著内容删掉，哪些必须保留

### 可以删掉或合并

第一版不需要完整表现：

- 面包店同事群像；
- 费伊的恋爱支线；
- 母亲与妹妹的大量童年回忆；
- 学术会议具体争论；
- 科学家之间的竞争；
- 收容机构的完整社会细节；
- 复杂医学解释；
- 原著进度报告中的全部事件。

这些内容在小说中有价值，但不一定适合固定相机的空间错视游戏。

### 必须保留

至少保留：

1. 查理想要变聪明；
2. 阿尔吉侬是先行者，也是对照；
3. 查理经历短暂高峰；
4. 阿尔吉侬先衰退；
5. 查理知道自己也会失去；
6. 查理最后给阿尔吉侬送花。

## 九、单关设计模板

每个关卡建议填写以下卡片：

```text
关卡名称：
章节位置：

本关玩家要感受到什么：
本关唯一的主要叙事动作：

玩家初始看到的状态：
可见但不可达的目标：
玩家应该形成的局部假设：

本关引入或复习的空间规则：
使用的机关：
合法 Snap 状态：
视觉候选连接：
连接成立的证据：
可能被拒绝的错误连接：

关键操作：
操作后产生的视觉变化：
CurrentEffectiveGraph 的变化：
角色如何证明路径成立：

关卡结束时的建筑状态：
关卡结束时的角色状态：
玩家带走的新规则：
下一关继承的新问题：

文本或声音是否必要：
如果删除文本，玩家是否仍能理解主要变化：
```

每关必须能写出一句玩法句子：

```text
玩家通过改变 X，使 Y 成为可达状态，
从而理解 Z。
```

如果一关无法写出清晰的玩法句子，通常说明机制、叙事目的或空间目标还没有收敛。

## 十、关卡与叙事的检查标准

### 玩法可读性

- 初始目标是否清楚可见？
- 玩家是否知道应该观察哪个机关？
- 机关操作是否能产生可观察结果？
- Snap 状态是否离散、稳定、可理解？
- 视觉连接是否有足够证据？
- 角色是否能证明路径真正成立？
- 失败后玩家是否知道哪个连接假设不成立？
- 重置是否足够快？

### 叙事服务玩法

- 本关是否有明确的进入动机？
- 叙事是否没有替代玩家观察？
- 重要变化是否绑定了建筑、角色或路径状态？
- 删除文本后，玩家是否仍能完成当前玩法？
- 过场是否产生新的可操作状态？
- 是否避免把每个机关强行解释成一个象征？

### 多关卡节奏

- 本章引入了什么新规则？
- 本章是否有复习和变奏，而不是连续堆新机制？
- 本章是否有一个视觉高潮？
- 本章是否有至少一个缓冲或留白段落？
- 下一章继承的是问题和理解，而不是单纯数值难度？
- 关卡是否保持自包含，又对整体阶段有贡献？

### 角色关系

- 阿尔吉侬是否有明确的操作或观察功能？
- 角色关系是否改变了玩家的行动或空间理解？
- 对话是否避免复述玩家刚看到的机关？
- 情绪峰值是否与玩法峰值合理重合、错开或递进？
- 是否保留足够留白，让玩家自行解释？

### 伦理与人物表达

- 是否避免把智力差异做成羞辱或惩罚？
- 是否避免把查理的衰退表现为玩家被强制降低操作能力？
- 是否保持“智力不是尊严来源”的底线？
- 阿尔吉侬是否是一个被记住的生命，而不只是剧情开关？
- 结尾是否避免把悲剧包装成奖励或胜利？

## 十一、当前项目的推荐实施顺序

本文不要求立即实现完整五章。建议按以下顺序推进设计验证：

### 阶段一：白盒验证核心节奏

先用现有最小关卡验证：

```text
不可达
  -> 旋转
  -> 错视连接成立
  -> 自动行走
  -> 目标抵达
```

这一关在剧情上暂时对应“看不见的出口”，即第一章 1-3，而不是最终完整游戏。

### 阶段二：扩展同一机制的三个变奏

围绕现有旋转和视觉连接，验证：

1. 单一候选连接；
2. 多个 Snap 状态中的正确状态；
3. 跨 Part、远处 Part 和遮挡拒绝。

这三类关卡可以同时承担第一章末尾和第二章前半的白盒。

### 阶段三：加入阿尔吉侬的轻量表现

优先只做：

- 远处提前走过一条路；
- 与查理的路径形成对照；
- 后期停在曾经可走的位置。

不要先做完整双角色同步控制。

### 阶段四：验证“旧连接失效”但不降低玩家能力

使用已有视觉候选评估和遮挡拒绝，设计旧路径不再成立的关卡。重点验证：

- 失效是否可观察；
- 玩家能否理解是空间连接改变，而不是操作失灵；
- 是否仍有稳定的局部固定边通往目标；
- 关卡重置和反馈是否足够温和。

### 阶段五：最后设计花园收束

花园不是最终复杂谜题，而是一个低复杂度的真实道路关卡。它的任务是收束情绪，不是证明玩家掌握了更多系统。

## 十二、授权与原创化边界

如果项目正式商业发布，直接使用以下内容通常需要确认改编授权：

- 查理·戈登；
- 阿尔吉侬；
- 爱丽丝·金尼安；
- 原著特定事件；
- 原著文本或改写文本；
- 原著中具有明确识别度的专有表达。

如果暂时没有授权，可以采用主题原创化：

- 将查理改为原创角色；
- 将阿尔吉侬改为另一种实验生物或陪伴对象；
- 保留“短暂获得看见世界的能力，最终回到真实道路并留下纪念”的主题结构；
- 不使用原著专有名字、段落和句子。

两种方向在关卡骨架上仍可以共用：

```text
愿望
  -> 实验
  -> 高峰
  -> 对照者先衰退
  -> 连接失效
  -> 真实道路
  -> 纪念
```

本节是设计和风险提示，不构成法律意见。

## 十四、最终设计原则

将本次调研压缩成项目可执行的原则：

1. 先确定玩家在本关要感受到什么，再确定需要解释什么；
2. 每一关只承担一个主要叙事动作；
3. 让主题进入路径、机关、角色位置或环境状态，而不是只进入对白；
4. 让玩家先做出行为，再理解行为的意义；
5. Path Graph 是玩法计算结果，不是叙事文本对象；
6. 文本只补充空间无法可靠表达的事实；
7. 机制先展示，再变奏，最后组合；
8. 失败应暴露错误的连接假设，而不是惩罚玩家；
9. 角色关系应有操作意义，但不应成为第二套竞争玩法；
10. 每个关卡需要一个清晰的视觉句号；
11. 章节以体验和认知切换组织，而不是只按地图分区；
12. 关卡节奏以惊喜密度为主，不以持续增加难度为主；
13. 旧机制的重新解释比每章增加全新系统更重要；
14. 查理的衰退应表现为世界连接逐渐失效，而不是玩家操作能力被降低；
15. 阿尔吉侬是对照物和被记住的生命，不只是剧情开关；
16. 结尾的花不是通关奖励，而是对一段关系的纪念；
17. 玩法、角色和空间状态必须形成完整链路：

```text
玩家做了什么？
  -> 玩家因此理解了什么？
  -> 这个理解为什么让角色或世界变得不同？
```

如果这三个问题能在一个关卡中闭合，玩法与叙事就不再是两条并行轨道，而是同一个设计系统。
