# 第四章关卡大纲与演出上下文

这份文件只记录第四章的剧情大纲、关卡功能、必须揭示的信息、当前导演演出和润色边界。具体对白请查看 `docs/story-chapter-4.md`。

---

## 一、第四章整体定位

第四章是查理从城市回到研究所后的“回返与承认”篇。

第二章中，查理沿着实验空间逐渐获得能力、建立信心并主动离开研究所；第四章则沿相反方向返回同一组旧实验空间，逐步看见能力背后的代价：

```text
2-4 出口与 Lift 空间
  → 4-1 回到研究所，发现空实验室并听见异常报告

2-3 滚筒寻路测试空间
  → 4-2 目击阿尔吉侬迟疑、停滞和衰退征兆

2-2 空间联系训练空间
  → 4-3 查理说出自己看不见世俗世界，并与研究员交锋

2-1 手术与最初测试空间
  → 4-4 研究员解释手术风险，查理接受自己的选择
```

第四章固定为四关，不增加额外关卡。

章节情绪节奏：

```text
悬念 → 目击 → 交锋 → 解释 → 接受
```

章节信息节奏：

```text
4-1：查理听见隔壁正在发生异常测试
  → 4-2：查理亲眼看见阿尔吉侬已经不一样了
  → 4-3：查理说明自己看不见世俗，研究员发现自己一直被查理看不见
  → 4-4：研究员解释手术与衰退时间线，查理承认并接受自己的选择
```

---

## 二、本章必须保持的统一事实

### 1. 查理的观测缺失

- 手术完成的瞬间，查理就失去了对世俗世界的空间观测能力。
- 这不是在第三章中逐渐衰退的能力。
- 第三章只是查理逐步发现、验证并确信这一事实。
- 查理仍然能够感知建筑、道路、桥梁和隐藏的空间连接。
- 查理无法观测行人、车辆、道路上的日常物件、旁人的活动痕迹、旁人的声音和城市生活回应。
- 城市并没有真的消失，也不是已经毁灭或废弃。
- 对查理而言，城市因为缺少所有世俗活动的空间回应，呈现为泡在雾里的“空城”。

润色时继续使用“空间观测”“感知”“接收”“看见路径”等第二章已经建立的概念，不要写成简单的视觉失明，也不要使用“查理的眼睛”替代这一设定。

### 2. 研究员一直在场

- 研究员在第二章的测试过程中实际可能一直与查理同处实验室或在现场观察。
- 查理没有观测到研究员的身体。
- 因此，查理把研究员的声音误认为广播、通讯设备，或隔壁、墙后的声音。
- 4-3 才明确揭示：研究员一直就在查理身边，只是查理从手术完成后就无法观测到研究员。

### 3. 阿尔吉侬的衰退时间线

- 手术前，阿尔吉侬没有现在的副作用。
- 查理离开研究所时，阿尔吉侬也没有明确的衰退迹象。
- 查理离开后，研究员才在日常测试中逐渐发现阿尔吉侬行动变慢、在熟悉路径上停滞、重复判断并无法顺利通过过去熟悉的路线。
- 4-2 只让玩家目击异常，并接受“只是太累了”的回避解释。
- 4-3 让查理与研究员围绕异常发生集中交锋。
- 4-4 才明确说明完整时间线，并将其与手术风险联系起来。

### 4. 研究员的态度

- 研究员不能在 4-1、4-2 一开始就主动解释全部真相。
- 研究员前两关会记录、回避、压低结论，使用“疲劳”“状态不佳”“还不能下结论”等说法。
- 研究员不是纯粹慈祥的导师，也不是简单的反派。
- 他既在观察实验结果，也在回避承认实验风险和研究所的隐瞒。
- 4-3 发生全章唯一一次集中争执。
- 4-4 不继续争吵，改为解释、承认、接受和陪伴的收束。

### 5. 查理的情绪变化

```text
4-1：我必须问个清楚
  → 4-2：我可以把路接好，也许能帮阿尔吉侬
  → 4-3：这不是疲劳，你必须回答我
  → 4-4：我承认自己选择过手术，也接受它带来的代价
```

查理不能在 4-2 突然失去寻找研究员的急迫感，也不能在 4-4 把责任全部推给研究员。他最终承认：自己当初因为急于改变而选择了手术；研究员则必须承认记录和隐瞒属于研究所。

## 三、第四章关卡功能总表

| 关卡 | 复用空间 | 关卡功能 | 本关必须揭示 | 本关不应揭示 |
|---|---|---|---|---|
| 4-1 | 2-4 出口与 Lift | 回到研究所、建立悬念 | 实验室空无一人，隔壁有异常报告，阿尔吉侬似乎被困住 | 手术真相、衰退原因、研究员与查理的完整交锋 |
| 4-2 | 2-3 寻路测试 | 目击阿尔吉侬异常 | 阿尔吉侬明显变慢并停滞，研究员暂称疲劳 | 手术风险、查理观测缺失的完整解释 |
| 4-3 | 2-2 空间联系训练 | 集中交锋、发现研究员一直在场 | 查理看不见整个世俗世界；查理一直看不见研究员 | 手术和衰退的完整时间线 |
| 4-4 | 2-1 手术与最初测试 | 解释、承认、接受 | 手术两面性、阿尔吉侬衰退时间线、查理接受选择并决定陪伴 | 不再引入新的悬念或争吵 |

# 四、4-1 空实验室

## 关卡定位

沿用第二章 2-4 的出口与 Lift 空间。查理从城市沿与第二章相反的方向回到研究所。

本关是第四章的悬念关，不解释真相，只完成空间转场和信息引导：

```text
城市 → 研究所
空实验室 → 隔壁声音
听见异常 → 立刻前往 4-2
```

### 本关必须揭示

- 查理已经回到研究所；
- 在查理的观测中，研究所实验室空无一人；
- 隔壁传来研究员断断续续的实验报告；
- 报告里出现“阿尔吉侬”“滞留”“失败寻找”“依然被困住”等词；
- 查理判断研究员在隔壁，并决定立即过去问个清楚。

### 本关不要揭示

- 不解释阿尔吉侬为什么衰退；
- 不解释手术的风险；
- 不发生争吵；
- 不让研究员现身并与查理完整对话；
- 不把报告写成清晰完整的说明书。

## 4-1 通用演出规则

- 本关进入时仍处于关卡雾 reveal 过程。
- 4-1 是唯一覆盖 `ShouldRunDuringFogReveal()` 的第四章导演。
- Lift 在雾淡出期间就开始下降，不等待雾完全散尽。
- 其他关卡的导演默认仍在雾完全 reveal 后才开始运行，不受这一机制影响。
- `modal` 锁点击和走路，玩家需要完成当前对白。
- `banner` 是底部条，默认不阻塞移动，适合报告和查理在行走中的短句。

## 4-1 Lift 入场

**触发：** 关卡稳定、`onLevelSettled` 被调用时，先启动 4-1 Director，再开始雾 reveal。

**玩家状态：** 锁输入、锁走路。查理出生在 Lift 上。

**画面：** Lift 从配置位置上方 `4.0` 米开始。雾仍在淡出，Lift 已经向下运动。

**运动参数：** Lift Part 为 `part_mainpart_1_2`；上方 offset 为 `4.0` 米；下降时长为 `4.0` 秒；缓动为 `EaseOutQuad`，由快到慢。下降过程中保持固定游戏相机，不额外让镜头跟随 Lift。下降结束后将 Lift 视觉位置和逻辑位置写回配置位置，玩家跟随 Lift 的视觉位置同步更新。

**这段在干什么：** 承接 3-4 的下降转场，让查理从城市回到研究所。Lift 的下降是画面主动作，雾效负责隐藏进关时的空间切换。

## 4-1 after_lift

**触发：** Lift 完成下降并回到配置位置后立即播放。

**玩家状态：** 锁输入、锁走路。`modal`。

**画面：** Lift 已经停稳，研究所结构逐渐从雾中清晰起来。查理仍站在 Lift 上，周围看不到任何人。

**这段在干什么：** 让查理确认自己已经回到研究所，同时立即指出实验室的空置感。具体台词见 `docs/story-chapter-4.md` 的 `ch4_1_after_lift`。

**说完：** 解锁玩家，查理可以开始寻找研究员。

## 4-1 path_observation

**触发：** 查理第一次开始走路后等待约 `1` 秒；只有 Lift 入场对白已经结束、当前没有其他 Story 播放时才开始。

**玩家状态：** 不锁输入。两段使用 `banner`，不阻塞查理继续走路。

**画面：** 查理离开 Lift，在空实验室中前进。没有研究员模型，也没有阿尔吉侬模型。远处或隔壁方向只有空的实验结构和门。

**这段在干什么：** 用断断续续的声音把玩家从 4-1 引向 4-2。报告不能让玩家直接听懂完整时间线，只提供异常关键词。具体台词见 `ch4_1_path_observation`。

**说完：** 无额外锁定。玩家继续走向门。

## 4-1 finish

**触发：** 查理到达隔壁房间门，`level.finish` 被导演接管。

**玩家状态：** 锁输入、锁走路。`modal`。

**画面：** 查理已经站在门前。门通向 4-2 的旧寻路测试房间，但下一关画面尚未出现。

**这段在干什么：** 明确查理不是被动进入下一关，而是主动决定穿过这扇门去找研究员。具体台词见 `ch4_1_finish`。

**说完：** 进入 4-2。

# 五、4-2 迟疑的轨迹

## 关卡定位

沿用第二章 2-3 的滚筒寻路测试房间。第二章里，阿尔吉侬表现得异常敏捷；第四章在同一空间里反向呈现它的迟缓和停滞。

本关不是竞速关，也不是解释关。重点是让玩家亲眼确认：

> 研究所回来了，但阿尔吉侬已经不一样了。

### 本关必须揭示

- 查理已经沿 4-1 的寻找行动进入测试房间；
- 阿尔吉侬在熟悉的测试中明显变慢；
- 阿尔吉侬会停滞、迟疑，甚至需要等待；
- 查理仍相信自己可以通过重新接通道路帮助阿尔吉侬；
- 研究员把异常解释成“太累了”或“需要休息”；
- 查理逐渐确认这不是一次普通疲劳。

### 本关不要揭示

- 不解释手术风险；
- 不完整说明阿尔吉侬衰退时间线；
- 不完整说明查理看不见世俗世界；
- 不发生 4-3 那种集中争吵。

## 4-2 intro

**触发：** 雾散、关卡稳定后，4-2 Director 开始播放。

**玩家状态：** 锁输入、锁走路。三段 `modal`。具体台词见 `ch4_2_intro`。

**画面：** 查理进入旧寻路测试房间。阿尔吉侬已经在 `part_staticpart_1_1:mouse_node`。研究员不出现身体，只通过声音回应。

**这段在干什么：** 保持 4-1 的急迫感。查理不是突然不找研究员，而是已经进入研究员所在的测试环境，并立即追问阿尔吉侬。

**说完：** 解锁玩家，同时启动阿尔吉侬的特殊探索。

## 阿尔吉侬迟缓探索

**触发：** `ch4_2_intro` 说完。

**玩家状态：** 玩家可以自由旋转 Part、寻找路径和走向出口。

**演出实现：**

- 通过 `SetAlgernonEnabled(true, MOUSE_NODE_KEY)` 启用阿尔吉侬；
- 使用 `StartAlgernonExploration(FINISH_NODE_KEY, options)` 沿当前有效寻路运行时进行探索；
- 使用 `SetAlgernonSpeed(0.82)` 降低移动速度；
- 使用已有探索暂停机制：`minPause = 1.4`、`maxPause = 2.0`、`candidateProbability = 0.0`；
- 导演通过 `IsAlgernonExplorationPaused()` 观察停滞状态；
- 导演不修改 Path Graph，不直接替阿尔吉侬决定道路。

**这段在干什么：** 让衰退表现为运行时的行动迟疑，而不是一个单独的对白结论。阿尔吉侬仍然使用当前有效的路径逻辑，导演只调整演出速度和观察到的暂停。

## 4-2 first_pause、second_pause 与 algernon_finish

- **`ch4_2_first_pause`**：阿尔吉侬第一次进入探索暂停状态时播放一段查理的 `banner`；具体台词见对应台词表。
- **`ch4_2_second_pause`**：阿尔吉侬第二次进入探索暂停状态时播放查理、研究员、查理三段 `banner`；研究员继续解释“只是需要休息”。
- **`ch4_2_algernon_finish`**：阿尔吉侬缓慢到达 `part_rotateablepart_1_2:finish_node` 后播放查理的 `banner`，确认它比过去更加吃力。

## 4-2 finish

**触发：** 查理接通道路并到达终点门，`level.finish` 被导演接管。

**玩家状态：** 锁输入、锁走路。三段 `modal`。

**画面：** 查理站在门前。阿尔吉侬的异常已被看见，但研究员仍没有给出完整解释。

**这段在干什么：** 查理继续追问；研究员暂时只说状态不佳、还不能说明；查理明确表示会继续问个明白。具体台词见 `ch4_2_finish`。

**说完：** 进入 4-3。

# 六、4-3 看不见的人

## 关卡定位

沿用第二章 2-2 的空间联系训练房间。第二章中，这里表达查理主动操控建筑、创造路径；第四章中，同一空间成为查理质疑手术、说出城市经历并与研究员交锋的场所。

本关是第四章唯一的集中交锋关。

### 本关必须揭示

- 查理继续追问阿尔吉侬的异常；
- 研究员仍试图让测试先于解释；
- 查理完整说出自己无法观测世俗世界；
- 查理确认这种缺失从手术完成瞬间就已经存在；
- 研究员第一次意识到查理一直看不见自己；
- 查理和研究员围绕隐瞒与“不能下结论”发生正面交锋；
- 研究员同意回到手术记录，进入 4-4。

### 本关不要揭示

- 不在这里完整解释手术风险；
- 不在这里交代阿尔吉侬完整衰退时间线；
- 不把争吵延续到 4-4；
- 不让查理马上完成接受。

## 4-3 intro 与 observation

- **`ch4_3_intro`**：进关后播放三段 `modal`。查理继续追问，研究员要求先完成测试，查理明确要求之后必须回答。具体台词见台词文档。
- 进关后解锁玩家，同时启动阿尔吉侬的慢速探索。玩家继续使用关卡既有旋转机关。
- **阿尔吉侬探索**：`effectiveGraphOnly = true`。只消费当前有效 Path Graph，不搜未评估通过的配置候选。终点还接不上时，在出生那段有效路上徘徊并停顿（`minPause = 3.0`、`maxPause = 5.0`）；查理拧对、有效图通了后再朝终点走。已生效的候选边上仍可能 30% 折返。导演不修改 Path Graph。
- **`ch4_3_observation`**：查理进入 `part_mainpart_1_2` 的入口区域时播放五段 `modal`，通过当前节点、当前边目标或当前 Part 判断进入。这里正式说出无法观测行人、车辆、生活痕迹，并让研究员意识到“你一直看不见我”。现行台词强调感知不到世俗、能感知阿尔吉侬，不在分镜里另写建筑/道路/桥梁点名。
- **`ch4_3_fault`**：查理第一次真正遇到该旋转机关的 stall / slip / slowSnap 时播放单段 `banner`。不锁操作。若当前已有剧情在播，等空档再播。只点操作失灵，不教拖拽，也不把结论扩大到手术风险。台词见 `ch4.3.fault.1`。

## 4-3 pause 与 algernon_finish

- **`ch4_3_pause`**：查理抵达 `part_mainpart_1_2:rotateable_node_end` 时播放单段 `banner`，把阿尔吉侬的停滞再次拉回对话现场。触发只看查理是否走到该节点，不订阅阿尔吉侬当时是否正在暂停。
- **`ch4_3_algernon_finish`**：阿尔吉侬抵达 `part_part:finish_node` 时播放单段 `banner`。如果当前 Story 正在播放，导演先挂起该段，等当前 Story 结束后再播放。

## 4-3 finish

**触发：** 查理到达终点门，`level.finish` 被导演接管。

**玩家状态：** 锁输入、锁走路。五段 `modal`。

**画面：** 查理站在门前。研究员仍没有可见身体；声音来自查理无法定位的存在。

**这段在干什么：** 查理确认研究员一直在场，质问研究员为什么隐瞒；研究员承认需要更多记录，并提出回到手术记录。争吵在本关结束，具体台词见 `ch4_3_finish`。

**说完：** 进入 4-4。

# 七、4-4 手术记录

## 关卡定位

沿用第二章 2-1 的手术与最初测试空间，让第四章在空间上回到一切的起点。

本关是第四章的闭合关，承担：

```text
解释手术 → 交代时间线 → 承认选择 → 接受代价 → 决定陪伴
```

### 本关必须揭示

- 手术让查理获得隐藏空间连接的观测和理解能力；
- 同一次手术切断了查理对世俗生活的观测；
- 查理从手术完成瞬间就已经失去这部分接收能力；
- 阿尔吉侬手术前没有明显副作用；
- 查理离开研究所时阿尔吉侬没有明确衰退迹象；
- 查理离开后，阿尔吉侬才逐步出现停滞、重复判断和寻路困难；
- 两种异常都属于手术带来的实验风险，但时间线不同；
- 查理当初因为急于改变而选择了手术；
- 研究所对记录和隐瞒负有责任；
- 查理接受已经发生的改变与代价，并决定陪伴阿尔吉侬。

### 本关不要做

- 不再引入新的悬念；
- 不再进行长时间争吵；
- 不把查理写成完全否认自己的选择；
- 不把责任全部推给查理或全部推给研究员；
- 不让结尾只停在“知道真相”，必须明确转向“陪伴阿尔吉侬”。

## 八、当前实现的导演登记与 API

第四章四关已经登记在 `LevelDirectorCatalog`：

```lua
ch4_1 = "LevelDirectors.Director4_1"
ch4_2 = "LevelDirectors.Director4_2"
ch4_3 = "LevelDirectors.Director4_3"
ch4_4 = "LevelDirectors.Director4_4"
```

当前导演职责：

| 导演 | 主要职责 |
|---|---|
| `Director4_1` | 雾 reveal 期间启动 Lift；Lift 由快到慢下降；播放空实验室、断续报告和门前对白 |
| `Director4_2` | 启用阿尔吉侬；降低速度；观察探索暂停；播放两次迟疑、终点和过关对白 |
| `Director4_3` | 启用慢速阿尔吉侬；监听查理进入旋转结构；播放城市观测说明、停滞反馈和集中交锋 |
| `Director4_4` | 播放手术解释；监听查理第一次走路并在停稳后说明阿尔吉侬时间线；播放最终接受对白 |

通用导演 API：

```lua
self:SetInputLocked(true / false)
self:SetPlayerLocked(true / false)
self:PlayStory(lines, options)
self:SetAlgernonEnabled(enabled, nodeKey)
self:SetAlgernonSpeed(speed)
self:StartAlgernonExploration(nodeKey, options)
self:SetAlgernonOnArrived(listener)
self:GetPlayer()
self:GetAlgernon()
```

这些 API 让演出层消费已有角色、寻路和 Story 生命周期，不让导演重新定义关卡连接。玩家仍然通过当前有效 Path Graph 走路，机关仍由关卡运行时负责。

## 九、润色时的硬性边界

- 不要改变任何台词的 `id`、`mode` 或 `style`。
- 不要把 `modal` 改成 `banner` 或反过来，除非先确认演出节奏和输入锁定也要改变。
- 不要删除 4-1 研究员的断续报告；它是从城市回到研究所的悬念桥。
- 不要让 4-2 的查理突然不再寻找研究员；他的追问从 4-1 连续到 4-3。
- 不要把 4-2 写成竞速关；阿尔吉侬先后到达不是胜负关系。
- 不要把阿尔吉侬的迟缓写成突然死亡或已经完成衰退；第四章只表现逐步衰退征兆。
- 不要在 4-2 提前解释手术风险。
- 不要在 4-3 之前完整说出查理无法观测世俗世界的手术原因。
- 4-3 只能有一次集中争吵；不要把 4-4 继续写成争吵。
- 不要让研究员在 4-3 直接交代阿尔吉侬完整时间线；时间线属于 4-4。
- 不要把“看不见世俗世界”写成“世界真的消失”或“城市毁灭”。
- 不要把查理最终写成只接受研究员的道歉；结尾必须明确决定陪伴阿尔吉侬。
- 不要在第四章新增第五关。第五章负责陪伴、失去、花园、墓地和送花。
- 不要把当前实现中的 API 名称、关卡 ID 或路径节点名改写成自然语言后再导回代码。

## 十、与第五章的衔接

第四章结束时，查理已经完成三件事：

1. 知道自己为什么只能感知建筑、道路和隐藏路径；

3. 接受自己当初的选择，并决定陪伴阿尔吉侬。

陪伴阿尔吉侬
  → 见证衰退与失去
  → 走向花园、墓地和真正的道路
  → 送花
